# 漲停預測力與成本結構

- 日期：2026-09-16
- 起點：使用者提問「每週抓一檔漲停，40 週複利 45 倍」
- 這份文件同時記錄**成立的發現**與**不成立的結論**

---

## 先講結論

| 主張 | 判定 |
|---|---|
| 訊號能預測漲停 | ✅ **成立**。漲停率 2.47% → 16.62%，6.7 倍 |
| 每週抓漲停可複利 45 倍 | ❌ 不成立。命中率 16.6% 不是 100% |
| 校準器＋門檻＋槽位在毀訊號 | ✅ **成立**。去掉三層，毛報酬從 5% 變 39% |
| 成本的大頭是手續費 | ❌ 不成立。滑價佔 63%，手續費只佔 13% |
| 40 日持有年化淨 33.6% 是可用優勢 | ❌ **不成立**。PBO 0.886、DSR 0.0075、4/8 年為負 |

## 成立的發現一：訊號真的預測得到漲停

```
標的池 273 檔｜2019-01 ~ 2023-12｜1,216 個交易日
漲停次數 2,165（每週約 8.9 檔）｜全天鎖死買不到的只有 4.7%

動能突破 Top3 的未來 5 日漲停率
  基準（隨機一檔）     2.47%
  Top 3               16.62%      6.7 倍
```

分數與漲停率的關係**不是單調的**，只有最高 1% 明顯跳起來：

```
分數分位     筆數      平均毛報酬   漲停率
最低 50%    47,927      0.15%     1.8%
50~80%      28,756      0.26%     1.6%
80~90%       9,585      0.19%     3.0%
90~95%       4,793      0.16%     4.6%
95~99%       3,834      0.38%     9.6%
最高 1%        959      0.85%    20.8%   ← 只有這一段有效
```

80~95% 區間比 50~80% 還差。**訊號只在極端值有資訊**，這與
`2026-09-16_箱內排序能力與優勢集中度.md` 的「優勢集中在薄箱」一致。

## 為什麼 45 倍的算式不成立

```
1.1^40 = 45.26 倍   前提是 40 週每週都賺 10%
```

實測拆解（動能突破 Top3、T+1 開盤進、5 日後收盤出）：

```
命中漲停  16.6% 的持倉   平均  +9.34%
沒命中    83.4% 的持倉   平均  −0.91%
加權                      +0.80%（毛）
```

三個斷點：

| 假設 | 實測 |
|---|---|
| 每週都抓到 | 命中率 **16.6%** |
| 漲停 = 賺 10% | 漲停那週只賺 **9.34%**——漲停是「某一天 +10%」，不是「那一週 +10%」 |
| 沒提到漏掉的 | 83.4% 沒命中，平均 **−0.91%** |

⚠️ **16.6% 與 100% 之間不是「再努力一點」的差距。** 完美預知的上限是
8×10¹⁹ 倍（實測），所以上限從來不是限制，**預測能力才是全部的問題**。

## 成立的發現二：成本的大頭是滑價，不是手續費

```
1.271% 來回成本的組成（中型股、零股）
  滑價   買+賣   0.8000%   63%   ← 最大
  證交稅 只賣    0.3000%   24%
  手續費 買+賣   0.1710%   13%
```

**手續費折扣幾乎沒用**：6 折砍到 2.8 折只省 0.091 pp。

但那 0.8% 是**零股**的假設。實際上：

```
40 萬 × 33% 單檔上限 = 132,000 元｜1 張 = 1000 股
標的池 265 檔中，買得起 1 整張的：153 檔 = 58%（股價 ≤ 132 元）
```

整股滑價約 0.1%（13 萬對大市值股幾乎無衝擊），來回成本從 1.271% 降到
0.671%——**砍掉一半**，而這是修正錯誤假設，不是調參數。

⚠️ 整股滑價 0.1% 是**估計值，未實測驗證**。

## 成立的發現三：校準器＋門檻＋槽位三層在毀訊號

同一個 `動能突破` 分數，兩種用法：

```
現行系統（校準器 → 門檻 → 槽位佇列）      60 日 CPCV 中位數 +5.06%
直接用原始分數選 Top 3、每 H 日換一次      40 日 年化毛 39.1%
```

差別在三層：

| 層 | 做了什麼 | 後果 |
|---|---|---|
| 校準器 | 分數 → 12 個等級的箱平均 | 解析度從連續變 12 級，造成大量平手 |
| 門檻 | 淨期望 > 0 且 > edge_z 個標準誤 | 實測 `edge_z` 1.0→2.5 對成交比毫無影響 |
| 槽位佇列 | 訊號排隊等槽位 | 99.8% 被擋，成交由排隊順序決定 |

**之前所有的診斷都指向這三層，不是訊號本身**：

```
箱內 IC = 0/18 箱      ← 分箱毀掉解析度
tie-break 偏差 17.5 pp ← 分箱造成平手
訊號/成交比 435:1      ← 槽位佇列
PBO 0.629 ~ 0.971      ← 選擇過程（校準+門檻）沒有資訊
```

**這個機制診斷成立，而且是本次最有價值的發現。**

## 不成立的結論：40 日持有的 33.6%

初測看起來很好：

```
持有 40 日、等權 3 檔、時點池、整股成本

組合                    毛/趟    年化淨
動能突破                 5.38%   33.6%   ← 
籌碼跟隨                 2.53%   12.3%
均值回歸                 1.48%    5.2%
等權全池（市場）          2.33%   10.9%
隨機 3 檔（100 次中位）   2.28%   10.5%
                        隨機 5%~95%：0.76% ~ 4.17%/趟
```

5.38% 超出隨機的 95% 分位。看起來不是市場 beta。

**但多重測試校正之後不成立：**

```
PBO = 0.886             ⚠️ > 0.5 判定過擬合
DSR = 0.0075            不通過
  年化 Sharpe      0.5775
  運氣的期望最佳值  0.9611   ← 掃 21 組（3 族 × 7 持有期），運氣就能拿到 0.96
```

**觀察到的 Sharpe 0.5775 遠低於運氣門檻 0.9611。**

逐年一看就明白：

```
2016  −3.06%/趟   累積  −19.6%
2017  +4.03%              +28.9%
2018  −2.13%              −16.2%
2019  −2.06%              −14.1%
2020 +16.26%             +123.7%   ←
2021  +5.11%              +27.9%
2022  −0.63%               −5.3%
2023 +23.38%             +124.0%   ←
```

**8 年裡 4 年為負。全部報酬來自 2020 與 2023 兩年，其他六年加起來約 −8%。**

CLAUDE.md：**PBO > 0.5 → 判定過擬合，不得進入 Top 3 排名。** 觸線。

## 下一步：一個直接源自這次提問的方向

現行校準器學的是**期望報酬**（60 日的），而實測顯示訊號在那個尺度很弱
（箱內 IC = 0），但在**漲停事件**上有 6.7 倍預測力。

**沒測過的是：把標籤換成「未來 5 日內是否漲停」去訓練。**

```
現在   分數 → 校準器 → E[60 日報酬]     箱內 IC = 0
未測   分數 → 校準器 → P(未來 5 日漲停)  基準 2.47% → Top3 16.62%
```

這不保證能賺錢——16.6% 命中率配 −0.91% 的拖累與成本，本次實測是不穩定的。
但它是**目前唯一有明確預測力的標籤**，而且直接來自這次的提問。

要做的話：

```
1. 把 P(漲停) 當標籤重擬校準器（不是期望報酬）
2. 用進場門檻的既有公式反推：P(漲停) 要多高才覆蓋成本
3. CPCV + PBO 驗證（這次的教訓：初測好看的東西校正後常不成立）
```
