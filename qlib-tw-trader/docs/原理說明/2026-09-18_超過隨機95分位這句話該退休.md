# 「超過隨機 95% 分位」這句話該退休，不是改個數字

- 日期：2026-09-18
- 起點：`taiwan-quant/CLAUDE.md:244` 的待辦「先前所有『超過隨機 95% 分位』的結論都要用新門檻重算」

- 更正對象：`../../../docs/需求規劃/202609/08_動能突破N10的樣本外結果.md`、

## 結論先行

**用正確的虛無假設重算，這句話的成立與否取決於一個測不到的假設。**

```
搬法                    嚴格虛無 95% 分位   動能突破 OOS   邊際        判定
加法（pp 位移不變）          +133.61%        +138.83%    +5.22 pp    成立
乘法（倍數不變）             +153.95%        +138.83%   −15.12 pp    不成立
```

兩種搬法都不比對方有道理。**當結論由一個無法檢定的選擇決定時，
那個結論就不是證據。**

而要真正測出來，必須在 OOS 區間跑 200 組隨機權重——**禁令 6 禁止**
（2024-01 ~ 2026-09-11 已用掉一次）。

所以正確的處置不是把 `+120.97%` 換成 `+133.61%`，而是**停止把這句話
當作證據使用**。

---

## 為什麼要重算

`08_動能突破N10的樣本外結果.md` 的核心證據之一：

> 贏隨機中位（+63.30%）**+88 pp**，且超出隨機的 **95% 分位**（+129.57%）

那個 95% 分位來自**弱虛無**：隨機抽 10 檔股票。

2026-09-17 我在 CLAUDE.md 把「必跑對照組」加了第四條「無資訊對照組」，
規格是**同一特徵集的隨機權重組合，稀疏度等於被比較策略的特徵數**。
理由當時寫錯了（見 `2026-09-18_持有期多算一天推翻了對照組的結論.md`），
但**規格本身是對的**——它嚴格於隨機抽股。

所以 2026-09-16 那批「超過 95% 分位」的結論，用的是已經被取代的門檻。

### 兩個虛無假設差多少（開發集實測）

開發集 2018-01-24 ~ 2023-10-26，36 期，H=40，N=10，淨/趟：

```
弱虛無（隨機抽 10 檔）95% 分位      +2.027%     ← 08 文件用的門檻
嚴格虛無（稀疏 4 特徵隨機權重）95%   +2.393%     ← 正確門檻
動能突破手工分數                    +3.086%
```

嚴格虛無的完整分布（200 抽）：

```
 5% 分位   −0.234%
50% 分位   +1.160%
90% 分位   +2.102%
95% 分位   +2.393%
99% 分位   +3.126%
最好一組   +3.740%    ← 贏過真策略
```

**門檻上移 +0.366 pp/趟。** 開發集邊際從 +1.060 pp 縮到 +0.694 pp。

⚠️ 成本相同故毛淨同幅：嚴格虛無也是取前 10 檔，
`random_median.cost_per_trip` 與 `hand.cost_per_trip` 實測都是 1.0832%。

⚠️ 那個 `3.11%` 的弱虛無門檻量在另一個開發集視窗上（08 文件 line 79
寫「逐年為正 7/8 年」，是 2015-2023 八年；我這次的 36 期是 2018-2023）。
**位移量因此是近似值，不是同視窗對照。**

## 換算到 OOS：為什麼兩種搬法會分家

OOS 2024-01-02 ~ 2026-08-26，16 期。把累積報酬化成每趟：

```
動能突破        累積 +138.83%   等價 5.592%/趟
弱虛無 95% 分位  累積 +120.97%   等價 5.080%/趟
                                邊際 +0.512 pp/趟
```

開發集的門檻位移是 **+0.366 pp/趟**（加法）或 **×1.1806**（乘法）。
OOS 的基準比開發集高一倍多（5.080% vs 2.027%），所以兩種搬法在
OOS 上差很遠：

```
加法   5.080% + 0.366 pp = 5.446%/趟   →  16 趟複利  +133.61%
乘法   5.080% × 1.1806   = 5.998%/趟   →  16 趟複利  +153.95%
```

**差 20 pp，而策略的邊際只有 18 pp。** 搬法的選擇比結論本身還大。

### 哪一種對？沒有依據

- **加法**假設隨機權重的優勢是固定的絕對量——與市場報酬水準無關。
- **乘法**假設它是報酬的固定比例——隨市場一起放大。

兩者都合理。要分辨必須在兩個不同報酬水準的區間各測一次嚴格虛無，
而我只有開發集一個點。

## 更致命的一點：這個邊際本來就量不出來

即使接受加法搬法（對策略最有利的那個），邊際是 **+0.146 pp/趟**。

開發集上同一個比較的配對標準誤：

```
動能突破 − 虛無中位   差異 +1.926 pp   SE 2.364 pp   t = 0.81   n = 36
2 SE = 4.73 pp
```

**+0.146 pp 是一個標準誤的三十二分之一。**

對 95% 分位的開發集邊際 +0.694 pp 也只有 0.29 SE。

⚠️ 而且百分位與配對檢定回答的是不同問題。嚴格虛無**最好那一組
（+3.740%）贏過真策略（+3.086%）**——200 組任意 4 特徵權重裡，
至少有一組比手工設計的分數好。

## 這句話原本承載的重量

`08_動能突破N10的樣本外結果.md` 列了七項開發集驗證，只有 DSR 不通過：

```
毛報酬 vs 隨機      4.89%/趟 vs 隨機 95% 分位 3.11%   ✅   ← 這一項
逐年為正            7/8 年，最差 −1.6%                ✅
CPCV 路徑           15 條全為正，5% 分位 +13.68%      ✅
look-ahead          物理截斷測試 0 筆不一致            ✅
survivorship        用時點標的池                       ✅
成本安全邊際         23.5 倍                           ✅
DSR                 0.0042 不通過                     ❌
```

第一項現在要降級為「量不出差別」。**七項通過六項變成通過五項**，
而不通過的那一項（DSR）本來就是唯一直接針對過度擬合的檢定。

⚠️ 這不推翻 OOS 沒有衰減（毛 4.89%/趟 → 7.60%/趟）那個觀察。
那是獨立的、而且方向對策略有利。**但 16 期，且 2024-2026 是 AI 集中
行情，等權全池只有 +61.45% 而 0050 有 +236.44%——那個區間對任何
10 檔分散組合都不友善。**

## 處置

### 1. 停止使用，不是換數字

三份文件的該段落加註指向本文，**不就地改寫**（禁令 9）。
換成 `+133.61%` 會把一個測不到的假設偽裝成量測結果。

### 2. 未來的策略用開發集的嚴格虛無當門檻

```
嚴格虛無 95% 分位（稀疏 4，H=40，N=10）   淨 +2.393%/趟
```

這是**實測值**，可以直接當門檻用，不需要任何搬法假設。
要求新策略的淨/趟超過它，並且**配對差異 > 2 SE**。

後者才是真門檻——動能突破過不了（0.29 SE）。

### 3. OOS 的門檻無法補測

禁令 6。前推帳本（2026-11-09 揭曉第一期）是唯一還沒被用掉的樣本外
區間。**那一份在開始之前就該把嚴格虛無寫進規格**，不要事後再補。

⚠️ 前推帳本目前記的是動能突破 N=10 H=40，見
`2026-09-16_前推帳本改記動能突破.md`。它記的對照組是弱虛無。
**這一項要在第一期揭曉前補上嚴格虛無的同期抽樣**——同期抽樣不算
用掉區間，因為它不看未來報酬，只是把權重抽樣的名單先記下來。

## 方法上的一點

這件事的形狀和持有期 off-by-one 一樣：**一個數字被當成門檻用了兩天，
而產生它的構造已經被更嚴格的構造取代。**

差別是這次沒有 bug。程式對、數字對、門檻對——**只是門檻的定義換了，
而引用它的六個句子沒有跟著換。**

```
off-by-one     六份 forward 實作，沒有單一來源
95% 分位       六處引用同一個門檻，沒有單一來源
```

門檻也需要單一來源。散落在 md 裡的 `+120.97%` 沒有任何機制會在
規格改變時提醒你。
