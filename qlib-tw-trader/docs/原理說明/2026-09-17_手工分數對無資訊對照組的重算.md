規格因此加了第四條對照組，而**先前所有「超過隨機」的結論都要用新門檻

## 對照組怎麼造

手工分數的形式是固定權重的稀疏特徵混合：

```python
_blend(parts=[_squash(row["momentum_20"], ...), ...], weights=[3.0, 2.0, 2.0, 1.0])
```

所以對照組保留**同一個形式**，只把手挑權重換成隨機權重：

```
每個決策日   32 個特徵各自取當日橫斷面分位（尺度無關）
每次抽樣     抽一組標準常態權重，套用到所有決策日
分數         分位 × 權重的加權和
選股         取前 10 檔
```

### 三個設計決定，每一個都會改變門檻高低

#### 1. 權重在時間上固定

一次抽樣 = 一組權重，套用到所有決策日。手工分數的權重不隨時間變，
所以對照組也不能變。**每期重抽會失去持續性，退化回隨機選股**——
又變成太弱的門檻。

#### 2. 允許雙向權重

手挑權重全為正，但方向是靠 `_squash(-x)` 內建的——**手挑同時選了
特徵和方向**。對照組若只給正權重，它連「RSI 越低越好」都表達不出來，
那是被綁住手的對照組。

#### 3. ⚠️ 稀疏度必須匹配（第一版做錯了）

第一版用 32 個特徵**全部非零**的密集隨機權重：

```
密集對照組（32 特徵）  淨/趟中位 +1.45%
純隨機選股             淨/趟中位 +1.05%     ← 只高 0.4 pp
標籤打亂的 LightGBM    淨/趟     +2.94%
```

**兩個虛無假設差 1.5 pp，不等價。** 原因是 32 個隨機正負權重會互相
抵銷、接近雜訊，而 LightGBM 的樹只在少數特徵上分裂（稀疏、集中）。

而手工分數也是稀疏的，逐一數出來：

```
_momentum_from_row        4   ma_ratio_20, momentum_20, momentum_60, volume_ratio_20
_chips_from_row           6   foreign_net_ratio_5/20, institution_agreement_20,
                              institution_strength, margin_to_volume_20, trust_net_ratio_5
_mean_reversion_from_row  4   bollinger_position_20, high_low_position_20,
                              ma_ratio_60, rsi_14
```

所以每個族用**自己的特徵數**當對照組的稀疏度。

**用密集對照組會得到一個過鬆的門檻——正是這整條規格要防的事。**
我差點在實作新規格的同時犯下新規格要防的錯。

## 結果（開發集 36 期，每族 200 組隨機權重）

```
持有全池（無成本）  +2.44%

策略族     稀疏   淨/趟   百分位  對照中位  對照最好  配對差異  標準誤    t     判定
動能突破     4   3.48%    98%   1.58%   4.16%  +1.89%  1.91%  0.99  量不出差別
籌碼跟隨     6   1.67%    65%   1.32%   3.54%  +0.34%  1.30%  0.26  量不出差別
均值回歸     4   0.49%    10%   1.58%   4.16%  −1.10%  0.98% −1.13  量不出差別
```

### 動能突破：98% 百分位，但那不是證據

98% 看起來很強，但兩件事必須一起看：

```
對照組最好的一組   +4.16%   ← 贏過動能突破的 +3.48%
配對檢定           +1.89%   SE 1.91%   t = 0.99
```

**200 組任意的 4 特徵權重組合裡，約有 4 組贏過手工挑的那一組。**
而配對檢定的標準誤（1.91 pp）與差異（1.89 pp）同量級。

百分位與配對檢定回答不同的問題：

```
百分位    「手工挑的權重比多少比例的任意權重好」   → 98%
配對檢定  「那個差異能不能與抽樣噪音分開」         → 不能（t = 0.99）
```

⚠️ 抽樣共用同一份歷史，**不是獨立策略**。用它算分位可以，
用它宣稱統計顯著不行——與 CPCV 的 15 條路徑同一個問題。

### 籌碼跟隨：65% 百分位，形同任意

+1.67%／趟、對照中位 +1.32%、t = 0.26。**與隨便挑 6 個籌碼特徵加權
沒有可量測的差別。**

而且它還有一個先前記錄過的問題：spread 0.54 pp < 成本 1.071%，
`has_discrimination` 只在 `weekly_plan_trailing.py` 檢查、回測從來沒檢查。

### 均值回歸：10% 百分位，比任意還差

+0.49%／趟，**低於 90% 的任意權重組合**，也低於持有全池（+2.44%）。

t = −1.13 所以「顯著較差」也量不出來，但方向明確。它目前仍在
`STRATEGY_FAMILIES` 裡、隨時可被選用——**這一項應該在任何推播路徑上
被停用，直到有人能說明它為什麼該存在。**

## 兩個對照組構造不等價，要用嚴格的那個

```
虛無假設                        淨/趟中位
純隨機選股（舊規格）              +1.05%
稀疏隨機權重（本文件）            +1.58%
標籤打亂的 LightGBM（最嚴格）     +2.94%
```

對最嚴格的那個重算動能突破：

```
動能突破 3.48%  −  標籤打亂 2.94%  =  +0.54 pp／趟   t = 0.35
```

**三個門檻的結論一致：一旦離開「純隨機選股」，動能突破的優勢就量不出來。**

### 為什麼標籤打亂的模型比隨機權重更強

推測（**未驗證**）：LightGBM 即使在打亂的標籤上，樹仍會沿著特徵分布
有結構的軸切分，預測值因此與「特徵極端程度」相關。而在這個標的池裡
特徵極端的名字（高動能、高波動）表現較好，所以打亂的模型繼承了一個
**具體**的傾斜；隨機線性權重給的是**瀰散**的傾斜。

這只是推測。要確認需要比較兩者選出的名字分布，尚未做。
