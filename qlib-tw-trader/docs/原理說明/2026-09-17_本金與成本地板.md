# 本金要多少才夠？成本地板說：本金不是瓶頸

- 日期：2026-09-17
- 起點：使用者提問「40 萬難以打敗買進持有，那最少應該要有多少本金？」
- 對應資料：動能突破 N=10、H=40 的 360 筆實際持倉（開發集）

---

## 先講答案

**本金從 40 萬加到無限大，總共只省 2.6 pp／年的成本拖累。**
而策略樣本外落後 0050 買進持有約 **22 pp／年**。

**本金能補上需要的 12%。瓶頸是訊號，不是資金。**

---

## 成本與本金的關係（實測 360 筆持倉）

用實際選中的持倉（不是假設的標的），逐檔判斷整股／零股：

```
總資金         每檔金額    整股比例   成本/趟   年化拖累   部位/日成交額
   400,000      40,000    26.1%   1.081%    6.8%      0.006%
   800,000      80,000    50.6%   0.943%    5.9%      0.013%
 1,500,000     150,000    68.1%   0.848%    5.3%      0.024%
 2,000,000     200,000    75.3%   0.807%    5.1%      0.032%
 4,000,000     400,000    88.6%   0.732%    4.6%      0.063%
10,000,000   1,000,000    95.8%   0.694%    4.4%      0.158%
30,000,000   3,000,000    99.2%   0.675%    4.3%      0.475%
無限                      100.0%   0.671%    4.2%         —
```

實際持倉的進場價分布：

```
中位 78.4 元   75% 分位 198.9 元   90% 分位 414.1 元   最高 4,710 元
```

一張 = 1,000 股，所以要讓**中位**的持倉買得起整張需要每檔 78,400 元
（總資金 78 萬）；要讓 **90%** 的持倉買得起整張需要每檔 414,100 元
（總資金 414 萬）。

## 邊際效益在 200 萬附近就幾乎耗盡

```
區間              年化拖累改善    佔總可省空間
40 萬 → 200 萬      1.7 pp         65%
200 萬 → 400 萬     0.5 pp         19%
400 萬 → 無限       0.4 pp         16%
                    ────
總可省空間           2.6 pp
```

**要拿就在 200 萬那個轉折點拿。** 再往上是遞減，而且——

### 超過 3,000 萬之後成本會回頭上升

```
總資金         部位/日成交額中位
   400,000        0.006%
10,000,000        0.158%
30,000,000        0.475%
100,000,000       1.585%   ← 市場衝擊開始咬
```

0.671% 那個地板假設市場衝擊可忽略。部位佔日成交額 1.6% 時那個假設不成立，
**實際成本會超過地板**。所以不是「越多越好」，是有一個區間。

（ETF 輪動那次就是踩到這件事：0053 一個 13.3 萬部位佔當日成交額 27.4%，
0.05% 的滑價假設完全失效。見 `2026-09-17_ETF輪動的否定.md`。）

## 那個 0.671% 地板由什麼組成

```
手續費   0.171%   買賣各 0.1425% × 6 折    可議，2.8 折可降到 0.080%
證交稅   0.300%   賣出千分之三              法定，不可改
滑價     0.200%   整股買賣各 0.1%           實證下限（490 筆持倉，半價差中位 0.0937%）
        ────────
        0.671%
```

**證交稅一項就佔地板的 45%，而且無法降低。**

手續費談到 2.8 折可以再省 0.091 pp（先前實測），但那是整個地板裡最小的
一塊——談判的力氣花在這裡回報很低。

---

## 為什麼 2.6 pp 補不上缺口

樣本外實測（2024-01 ~ 2026-09，已用掉的區間）：

```
動能突破 N=10 H=40   總報酬 +138.83%   年化約 38.2%
0050 買進持有        總報酬 +242.15%   年化約 60.5%
                                      ────────
落後                                    22.3 pp／年
```

**可省的 2.6 pp 對上 22.3 pp 的落差。** 差一個數量級。

### 更根本的問題：開發集上本金根本不是問題

```
開發集毛報酬   4.20%/趟 → 年化毛 29.8%
開發集成本     6.8%（40 萬）
開發集淨       約 23%  >  0050 的 15.3%
```

**在開發集上，40 萬的成本已經足夠低，策略本來就贏。**
問題是樣本外毛報酬崩掉了——而 PBO 0.886 事先就說會這樣。

同一個 PBO 0.886 的訊號，給它 200 萬還是 PBO 0.886 的訊號。

---

## 本金真正買到的是什麼

不是報酬，是**回測的可信度**。

```
零股滑價 0.3%／0.4%   來自 CLAUDE.md 禁令 4 的明文規格，不是實測
整股滑價 0.1%         來自 490 筆實際持倉的跳動單位半價差中位 0.0937%
```

40 萬時 74% 的持倉走零股，也就是 74% 的成本依賴一個**規格值**而非實測值。
200 萬時 75% 走整股，成本主要依賴實測值。

**所以更多本金讓你更相信自己的回測，不是讓回測變好看。** 那是有價值的，
但不是「本金到了就能賺」。

---

## 所以最少要多少

這個問題的正確形式不是「多少本金才夠」，而是：

```
問法一   本金多少才能把成本壓到接近地板？        約 200 萬（拿到 65% 的可省空間）
問法二   本金多少才能打敗買進持有？              沒有這個數字——瓶頸不是本金
```

如果問的是第二個，答案是：**先讓訊號的 PBO 降到 0.5 以下，再談本金。**
在那之前，加本金只是把一個 PBO 0.886 的策略放大。

而目前唯一在累積、不消耗任何區間的證據是前推帳本
（`momentum_top10_h40@v1` 與 `momentum_top10_h40_c@v1`，
2026-11-09 揭曉第一期）。3 年 19 期才與已用掉那次 OOS 同量級。

## 限制

⚠️ 上表用的是**開發集的實際持倉**（360 筆）。不同策略選出不同價位的
名字，成本曲線會不同——這張表不能套到別的策略上。

⚠️ 市場衝擊只用「部位／日成交額」當代理，沒有實測衝擊成本。
3,000 萬以上的那兩列是外推，不是量測。

⚠️ 「年化拖累 = 成本/趟 × 252/H」是線性近似，忽略複利。
H=40 時誤差可忽略。

⚠️ 沒有考慮零股與整股的**時間成本差異**（盤中零股撮合頻率低於整股）。
那會讓零股的實際滑價高於 0.3%，方向是讓小資金更不利。
