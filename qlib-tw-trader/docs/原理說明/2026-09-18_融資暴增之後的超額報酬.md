## 為什麼換成事件法就測得出來

排序法的檢定力在 2026-09-18 已經用盡：

```
排序法   N=10 H=40 36 期   每趟 sd 15.4 pp   最小可測效應 5.0%／趟
                          實測效應 3.1%／趟 —— 低於門檻，看不見
事件法   1,172 個交易日     SE 0.328%        最小可測效應 ≈ 0.7%／趟
```

**同一份資料,換觀測單位換來 7 倍檢定力。** 不是換策略,是換問法。

### 觀測單位必須是「日」

漲停與融資暴增在橫斷面上叢聚,同一天的事件後續報酬高度相關。把每個
(股票, 日) 當獨立樣本會把 n 從 1,172 虛增到 3,179,SE 虛減 1.6 倍。

所以先算每日事件組的平均,再把「日」當樣本。
`test_event_study_counts_dates_not_stock_events` 釘住這件事。

## 三個排除confound的檢查

### 1. 不是動能

融資餘額會隨股價上漲而增加,所以「融資暴增」可能只是「今天大漲」的
代理。實測不是：

```
子集                      事件數    日數      超額      t
全部融資暴增               3179   1172   +1.709%  +5.21
融資暴增 且 當天 < +2%      2214   1050   +2.018%  +5.43
融資暴增 且 當天 < 0%       1434    821   +2.226%  +4.42
融資暴增 且 非漲停          3096   1172   +1.704%  +5.17
```

**當天下跌的子集效應最大（+2.226%）。** 那是動能的反面。

事件當天的漲跌幅分布：中位數 +0.19%、平均 +0.63%、5% 分位 −5.49%。
**分布中心在零附近,不是大漲日的集合。**

與漲停的重疊只有 2.65%(3,250 筆裡 86 筆)。

### 2. 沒有 look-ahead

融資餘額由交易所在當日收盤後公布,所以 T 日知道、T+1 開盤進場是合法的。
驗證資料對齊用恆等式：

```
balance[T] = balance[T−1] + margin_buy[T] − margin_sell[T]
```

2330 在 2023-06 的 19 個交易日全部成立(殘差 −7 ~ −13,那是現償未計入
buy/sell)。**所以 `margin_balance` 是 T 日的收盤餘額,不是前一日。**

分位門檻用 `expanding_quantile_mask`,只用 ≤ t 的資料(禁令 1)。
標的池用時點成員(禁令 2)。

### 3. 進場價含跳空

`forward[T] = closes[T+H] / opens[T+1] − 1`。T+1 開盤進場,**跳空幅度
算進成本**。不可以用 T 日收盤,那會憑空賺到跳空。

`locked_all_day`(一價到底,買不到)的變體另外報：漲停未鎖死 +3.086%
vs 全部漲停 +3.123%,差異很小,所以結果不是被買不到的日子撐起來的。

## 但成本地板吃掉三個持有期

超額隨持有期單調上升,而成本/趟幾乎不隨持有期變(N=10 時 1.068% ~ 1.103%)。
所以：

```
 H   毛超額/趟     淨/趟    每年趟數     年化增量
 5    0.306%   −0.775%     50.4     −32.43%
10    0.600%   −0.481%     25.2     −11.45%
20    0.793%   −0.288%     12.6      −3.57%
40    1.709%   +0.628%      6.3      +4.02%
```

**只有 H=40 淨值為正。** H≤20 的超額全部低於 1.081% 的成本地板——
統計上顯著,經濟上虧錢。這與整個專案的其他結論一致：**成本是約束。**

### 40 萬下的增量（相對持有全池）

```
 N   每筆金額    成本/趟     淨/趟    年化增量          年化區間
 3    133,333   0.834%  +0.875%   +5.64%  [ +1.38%, +10.14%]
 5     80,000   0.964%  +0.745%   +4.79%  [ +0.55%,  +9.26%]
10     40,000   1.081%  +0.628%   +4.02%  [ −0.19%,  +8.47%]
15     26,667   1.132%  +0.577%   +3.69%  [ −0.51%,  +8.13%]
20     20,000   1.194%  +0.515%   +3.29%  [ −0.89%,  +7.71%]
```

⚠️ **N≥10 的區間下界已經碰到零。** 點估計 +4% 但下界 −0.19%——
統計上過了多重測試,經濟上仍然可能是零。

⚠️ **N=3 的數字最好是因為成本最低,不是因為策略更好。** 而 N=3 只能
抓到 2.8% 的事件(見下),實際結果會由「剛好持有哪 3 檔」決定。

## 容量問題：40 萬抓不到全部

```
事件密度 2.7 檔/日
 N    H   每日可開新倉   可抓比例   需要同時持有   每筆金額
 3   40        0.07      2.8%        108    133,333
10   40        0.25      9.2%        108     40,000
20   40        0.50     18.4%        108     20,000
50   40        1.25     46.1%        108      8,000
```

要全抓需要同時持有 **~108 檔**(2.7 檔/日 × 40 日)。
40 萬 ÷ 108 = **3,700 元/檔**——低於零股成本地板,而且很多股票
一股都買不到(例如 3653 一股 5,765 元)。

隨機取子集不影響**期望**超額,但變異會放大。N=10 抓 9.2%,
實際年度結果的離散度會遠大於 +4.02% 這個點估計。

## 一個反直覺的副產品

**外資買超極端之後是負超額**(−0.022% ~ −0.308%,H=10 時 t = −1.94)。

沒有過多重測試,所以不是結論。但方向與「跟著外資買」的普遍說法相反,
而且四個持有期全部為負。值得單獨追。

同樣地,融資暴增為正也與「融資是散戶追高的反向指標」相反。
**兩個結果都指向同一個方向：台股的籌碼面共識可能是錯的。**

⚠️ 這是推測,不是實測。要確認需要把兩者的名單分布拿來比對。

## 我自己在這份分析裡犯的錯

腳本第一版的多重測試門檻拿「超額」去比一個用**中位數 SE** 算出的
單一門檻。各格 SE 差 61 倍(0.103% ~ 6.305%),結果它挑出：

```
連兩根漲停／H=40   超額 +3.399%   ← 「超過運氣門檻,值得追」
                   實際 n=34 日、SE 6.305%、t = 0.54
```

**那是整張網格最沒有訊息的一格,被選成最好的。**

t 值已經除掉各自的 SE,所以只能比 t。已改成
`multiple_testing_thresholds` 回傳 Gumbel 與 Bonferroni 的 t 門檻。

**教訓與 2026-09-18 其他幾件同形：我差點把一個雜訊最大的格子當成發現,
而理由是門檻算錯。**
