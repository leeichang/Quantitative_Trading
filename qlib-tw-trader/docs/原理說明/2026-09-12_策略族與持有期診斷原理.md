- 日期：2026-09-12
- 程式：`taiwan-quant/taiwan_quant/strategies/families.py`、`scripts/diagnose_families.py`
- 測試：`taiwan-quant/tests/test_strategies.py`（20 個測試）
- 實測輸出：`taiwan-quant/reports/family_diagnosis.txt`

---

## 問題

momentum 基準在 5 日持有期下，校準後最佳勝率 22.06%，門檻 40.22%。差 18 個百分點。

兩條可能的出路：

1. **換策略族** —— 籌碼跟隨或均值回歸的基礎勝率是否有本質差異？
2. **拉長持有期** —— 門檻 = (stop + cost) / (target + stop)，持有期拉長會讓 target 變大，門檻隨之下降

本診斷同時掃這兩個維度，讓資料決定。

---

## 三個策略族（D7）

| 族 | 組成 | 假設 |
|---|---|---|
| **動能突破** | 20/60 日動能 + 20 日均線偏離 + 量能倍數 | 近期強勢且帶量的標的續強 |
| **籌碼跟隨** | 外資 5/20 日買賣超 + 投信 5 日 + 三大法人一致度 + 融資使用率（反向） | 法人一致買超、散戶未過熱的標的續漲 |
| **均值回歸** | RSI（反向）+ 布林位置（反向）+ 高低位置（反向）+ **60 日均線偏離（正向）** | 長期趨勢未破壞下的超賣是機會 |

### 均值回歸的關鍵設計：長均線閘門

```python
parts = [
    _squash(-(row["rsi_14"] - 50.0), 0.06),            # 越超賣越高分
    _squash(-(row["bollinger_position_20"] - 0.5), 3.0),
    _squash(-(row["high_low_position_20"] - 0.5), 3.0),
    _squash(row["ma_ratio_60"], 12.0),                  # ← 這條是閘門
]
```

最後一項權重最高（3.0）。它是「拉回承接」與「接下墜的刀」的分界線：

> 超賣只有在長期趨勢未破壞時才是機會，跌破長均線就是趨勢轉空。

測試 `test_mean_reversion_penalizes_broken_long_ma` 隔離這個變數——兩檔都在最後 8 天急跌 3%/日（超賣程度相同），差別只在前段趨勢。

### 分數不是機率

三族的輸出都映射到 [0, 1]，但**不是機率**。校準（`validation/calibration.py`）負責把它映射成真實勝率。

所以測試重點不是「分數對不對」，而是：

1. **方向正確**——方向錯了整個策略會反向操作，而回測仍會跑出數字
2. **有界**——極端行情的離群值會拉壞校準分箱
3. **缺資料回 NaN**——不猜
4. **通過物理截斷掃描**——策略族是模型輸入端，它若偷看未來，後面所有驗證都白做

## 兩個測試構造的教訓

寫測試時三條失敗，全都是**測試構造錯**而非實作錯。值得記錄。

### 教訓 1：放大整個視窗等於沒放大

```python
# ✗ 錯誤：最後 20 天全部放量
expanded.iloc[-20:, vol_col] = 5000
```

`volume_ratio_20 = volume / 20日均量`。整段放大會讓**分母同步上移**，比值回到 1.0。

```python
# ✓ 正確：只放大最後 3 天
expanded.iloc[-3:, vol_col] = 5000
# 手算：(17×1000 + 3×5000)/20 = 1,600，比值 = 5000/1600 = 3.125
```

### 教訓 2：純上升趨勢不是「健康基準」

我原本寫：

```python
# ✗ 錯誤：把純上升趨勢當健康基準
healthy = trend_bars(300, 0.003)     # 純上升
broken  = trend_bars(300, -0.004)    # 純下跌
assert mean_reversion_score(healthy) > mean_reversion_score(broken)
```

失敗了：健康 0.334、破壞 0.655。

**但實作是對的。** 純上升趨勢 RSI = 100，是**超買**，均值回歸族本來就該給低分。純下跌 RSI = 0，是超賣，給高分是正確的——只是它同時跌破長均線該被扣分。

我的測試把兩個變數（超賣程度、長均線是否守住）混在一起了。

正確做法是隔離單一變數：

```python
# ✓ 兩檔都在最後 8 天急跌 3%/日（超賣程度相同）
intact = with_selloff(0.004)    # 長期上升，跌完仍守住 60MA
broken = with_selloff(-0.004)   # 長期下跌，早已跌破
```

> **測試失敗時，先問「是實作錯還是測試構造錯」。**
> 直接改實作去迎合測試，會把正確的行為改壞。

## 結論一：持有期的影響是策略族的 10 倍

```
持有期     門檻      三族最佳勝率       結果
 5 日    40.09%    21.94 ~ 23.19%    全部失敗（差 17~18 pp）
10 日    32.59%    25.30 ~ 26.79%    全部失敗（差 6~7 pp）
20 日    23.96%    25.09 ~ 27.11%    全部勉強通過（+1~3 pp）
40 日    16.03%    23.63 ~ 26.53%    全部通過（+7.6~10.5 pp）
60 日    12.57%    21.39 ~ 23.23%    全部通過（+8.8~10.7 pp）
```

**同一持有期下，三族的差異只有 1~3 個百分點。**
**持有期從 5 日到 60 日，門檻從 40.09% 降到 12.57%，差 27.5 個百分點。**

### 為什麼門檻會降這麼多

門檻 = (stop + cost) / (target + stop)

三個變數的變化：

| 持有期 | 平均目標 | 平均停損 | 一趟成本 | 門檻 |
|---|---|---|---|---|
| 5 日 | 6.46% | 2.54% | 1.071% | 40.09% |
| 60 日 | 25.68% | 2.47% | 1.071% | 12.57% |

**停損幾乎不變**（都是 ATR×0.8，約 2.5%），但**目標從 6.46% 長到 25.68%**——因為 60 個交易日有更多時間移動，85 分位數的報酬自然大得多。

分母變大四倍，門檻就掉下來了。

### 換手率的連帶效應

```
 5 日｜週換手 100.0%｜年化成本 55.69%
60 日｜週換手   8.3%｜年化成本  4.64%
```

年化成本從 55.69% 降到 4.64%，降了 **12 倍**。

這與 qlib-tw-trader 的實測教訓一致：**持有期是成本的主導因素。**

## 結論二：優勢主要不是來自策略

這是本次診斷最重要的發現，也是我特地加上「隨機優勢」欄位的原因。

```
組合                    總優勢    隨機貢獻   策略貢獻
均值回歸 × 60 日       +10.66%   +6.90%    +3.76%
籌碼跟隨 × 60 日        +9.34%   +6.90%    +2.44%
動能突破 × 60 日        +8.82%   +6.90%    +1.92%
```

### 隨機優勢是什麼

```
隨機優勢 = 基礎勝率 − 門檻
```

若這個值為正，代表**隨便買一檔、照這組柵欄持有，就能跨過門檻**。策略完全沒有貢獻。

60 日持有期下：基礎勝率 19.47% > 門檻 12.57% → 隨機選股也能過。

**15 組中有 6 組是這種情況。**

### 這代表什麼

三個策略族的鑑別力（最佳分箱勝率 − 基礎勝率）只有 **+1.2 ~ +5.4 個百分點**。

換句話說：**這三個策略族幾乎沒有選股能力。** 它們之所以「跨過門檻」，主要是因為 60 日持有期把門檻壓低了，而不是因為它們挑到了好股票。

## 結論三：這個「優勢」很可能是多頭市場的產物

60 日持有期的柵欄結構是：

```
目標 25.68%、停損 2.47% → R:R = 10.4
損益兩平勝率 = 1/(1+10.4) = 8.8%
加成本後門檻 = 12.57%
實際基礎勝率 = 19.47%
```

看起來期望值為正：`0.1947 × 25.68% − 0.8053 × 2.47% − 1.071% = +1.94%/趟`

### 為什麼要懷疑

1. **訓練期 2023-2025 是台股大多頭。** 「19.47% 的機率在 60 天內漲 25.68%」這個基礎勝率，是那段行情的產物。
2. **目標是用同一段資料的 85 分位數推導的。** 多頭市場的分位數本來就高。
3. **停損只有 2.47%，持有 60 天。** 這是一個極度不對稱的賭注——80% 的機率虧 2.5%，20% 的機率賺 25.7%。這種結構對市場環境極度敏感。
4. **樣本重疊。** 決策日每 5 天取一次，但持有 60 天 → 連續 12 個樣本的持有期重疊，有效獨立樣本數遠小於 3,441。

### 這正是必須跑 Walk-Forward + OOS 的理由

診斷只看訓練期的標籤分布。**它證明的是「這組參數能產出可用的訓練集」，不是「這個策略會賺錢」。**

腳本結尾明文寫著：

```
⚠️ 本診斷只看標籤分布與校準勝率，未跑 Walk-Forward、未計對照組。
```

## 多重測試警告

本網格掃 15 組。**掃越多組，最好的那組越可能是運氣。**

三條處理：

1. **列出全部 15 組**，不只最佳。讀者看得到完整分布，才能判斷「最佳」是不是離群值。
2. **回報試驗數 N = 15**，供後續算 Deflated Sharpe。
3. **明文要求**任何勝出組合仍須走完整 Walk-Forward + OOS + PBO。

從分布本身也能看出端倪：同一持有期的三族結果非常接近（相差 1~3pp），這說明**差異主要來自持有期而非策略**——若某一族真的有優勢，它應該在所有持有期都明顯勝出，而不是跟著持有期一起浮沉。

## 對使用者需求的影響

使用者原始需求是「未來 **5 個交易日**」，並說：

> 但是系統分析後如果一定要拉長持有期才可以！也可以建議！下週購買持續持有 3 個月

**資料的答案是：5 日不可行，必須拉長。**

```
 5 日：三族全部失敗，差 17~18 個百分點
20 日：勉強通過（+1~3 pp），但隨機優勢為負（−0.63%），策略要真的有用才行
40 日：通過（+7.6~10.5 pp）
60 日：通過（+8.8~10.7 pp），約 3 個月
```

### 但「通過」不等於「可以買」

三個理由要先解決：

1. **鑑別力太低**（1.2~5.4pp）——優勢主要來自柵欄結構，不是選股
2. **未跑 OOS**——訓練期是多頭，樣本外可能崩掉
3. **未計對照組**——必須並列「買進持有」與「0050」。60 日持有期、R:R 10.4 的策略，很可能還是輸給單純持有 0050
