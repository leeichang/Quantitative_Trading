# 交易日缺口驗證與守門

## 結論先行

開發集 2015-01-01 至 2023-12-29 中，候選池曾出現的 72 檔股票共有
683 個無價日（164 個單日、95 段連續區塊，共 519 個區塊日）。FinMind
逐日回查後，683 日全部沒有正值 OHLC；TWSE 官方端點抽查亦回傳零成交與
`--` 價格。因此這批資料不能當成資料庫漏列補寫，更不能以前值或 0 偽造成交。

資料庫在修復前後都是 2,914,166 列，本次實際補寫 **0 列**。這是一個推翻
工作假說的結果，不是修復失敗。原始證據保存在 `data_integrity_before.json`、
`data_gap_backfill.json` 與 `data_integrity_after.json`。

## 缺口全貌與決策影響

全市場共 548 檔在自身首末有價日之間存在缺口，合計 24,967 日；其中單日
8,280 日，連續區塊 3,475 段、16,687 日。免費 API 額度下，本次完整逐日驗證
的是所有曾進前 150 名的 72 檔、683 日，沒有宣稱其餘股票已經外部驗證。

以 40 日持有、40 日決策步長計算，缺口碰到 11 個「候選股 × 進/出場角色」，
分布在 8 個決策日。這些日期過去會在 `dropna()` 中靜默消失；現在
`assert_holding_price_completeness` 會在 T+1 開盤或 T+H 收盤缺價時明確拋出
`DataIntegrityError`。停牌不是可成交價格，明確失敗比悄悄縮小候選池正確。

## 為什麼 dataset 改成左連接

價格是交易日曆與報酬的主體；籌碼缺值只代表某項特徵不可用。舊的 inner join
讓籌碼缺值連價格日一起刪除，造成價格型動能訊號的日曆與排名被無關資料改寫。
現在以價格為左表保留每個有價日，籌碼欄位允許 NaN，由真正使用該特徵的下游
自行處理。

這個修正使下市診斷的政策 A 毛報酬由 4.9307%/趟升至 5.2015%/趟，淨報酬由
3.8747%/趟升至 4.1430%/趟（約 +0.2708 個百分點）。方向雖然變好，但不是調參；
它來自「籌碼缺值不再刪除價格日」這個可獨立驗證的機制修正。

## 既有下市推論的更正

舊報告把配對 `t=-1.00` 寫進結論，但 48 期中只有一個差值非零；此時 t 值只是
單一非零觀測的代數產物，不具推論意義。完整性修正後，政策 A/B 在 48 期、
480 筆成交上逐位相同，平均差與標準誤均為 0。這只表示本次 N=10 路徑沒有
觸發兩政策差異，不表示最後有價日結算原則可以移除。
