# LightGBM baseline：模型沒有贏，而且「隨機對照組」一直是錯的門檻

- 日期：2026-09-17
- 對應程式：`models/lgbm_baseline.py`（新增）、`scripts/validate_lgbm_baseline.py`（新增）
- 測試：836 passed（之前 819）
- 原始輸出：`taiwan-quant/reports/lgbm_baseline_dev.json`

---

## 先講結論

| 主張 | 判定 |
|---|---|
| LightGBM 比手工分數好 | ❌ 差異 +0.16%／趟，**t = 0.07** |
| 模型有預測能力（對正確虛無假設） | ❌ +0.70%／趟，**t = 0.54** |
| 模型贏過隨機選股 | ✅ +2.58%／趟，t = 2.56——**但這個門檻是錯的** |
| CLAUDE.md 的「隨機進場」是合格的對照組 | ❌ **一個沒有任何預測資訊的模型也能顯著贏它** |

**最重要的不是模型沒用，是對照組一直設錯。**

## 為什麼現在做 LightGBM

CLAUDE.md「明確不做」：

```
❌ 深度學習（先有 LightGBM baseline）
```

而到目前為止所有工作都在改**機制**與**成本**，訊號本身一直是手工分數。
累積的否定清單顯示那兩條已經挖完：

```
週頻抓漲停   否定    三族合成   否定    新聞   否定
ETF 輪動     否定    本金       不是瓶頸（可省 2.6 pp vs 需要 22 pp）
```

**剩下唯一沒動過的是訊號本身。**

## 比較的條件

```
決策日     完全相同（開發集、暖機 750、每 40 日一次，36 期）
標的池     完全相同（時點市值前 150）
標籤       完全相同（T+1 開盤買、T+41 收盤賣）
持倉數     完全相同（N=10）
成本       完全相同（逐檔 resolve_tier，禁令 4 的 large 分層）
唯一差別   排序用 LightGBM 預測，還是手工分數
```

### 未調參，所以 n_trials = 1

`DEFAULT_PARAMS` 固定一組、`NUM_BOOST_ROUND = 200`，**不掃超參數**。

掃參數會讓多重測試懲罰爆掉——先前掃 126 組時 DSR 0.0042、掃 16 組時
PBO 0.625~0.750。**一個未調參的 baseline 的 n_trials 是 1，那是它
最有價值的性質。**

### 目標是橫斷面排名，不是絕對報酬

絕對報酬裡同一天所有名字共享大盤漂移，模型會去學「大盤會漲」。
而我們的用法就是橫斷面選前 N 檔，所以排名才是對的目標。

## 表面上模型贏了

```
組合                    期數   毛/趟   成本/趟  淨/趟    年化   Sharpe  逐年正
LightGBM baseline       36   4.62%  0.986%  3.64%  20.8%   0.79   6/6
手工分數（動能突破）      36   4.56%  1.081%  3.48%  16.2%   0.57   5/6
隨機 10 檔（200 次中位）  36   2.14%  1.081%  1.05%   4.4%   0.31   4/6
等權全池（無成本）        36   2.45%  0.000%  2.45%  13.9%   0.71   5/6
```

年化 20.8% vs 16.2%、Sharpe 0.79 vs 0.57、**6/6 逐年為正**、贏隨機
t = 2.56 顯著。

**那個輪廓正是資料洩漏的特徵**（先前 14 個 bug 裡大部分都是這樣被抓到的），
所以跑了標籤置換檢定。

---

## 置換檢定：破壞掉預測關係，優勢還在 81%

做法：**在每個日期之內打亂標籤**後重新訓練。資料的形狀、缺值模式、
橫斷面結構全部不變，只有「哪一檔對應哪個排名」被破壞。

```
真模型      淨/趟 +3.64%
標籤打亂    淨/趟 +2.94%    ← 保留 81%
隨機 10 檔  淨/趟 +1.05%

打亂 − 隨機 = +1.88%／趟   標準誤 0.81%   t = 2.32   「顯著較好」
```

**一個證明沒有任何預測資訊的模型，顯著打敗隨機選股。**

### 這不是管線洩漏

單元測試釘住了淨化邊界（`test_purge_boundary_is_exact`、
`test_last_training_row_label_resolves_before_prediction`）。
真正的原因是：

**用任意函數取前 10 檔 ≠ 均勻隨機抽 10 檔。**

任意函數會繼承一個**因子傾斜**——它總是偏向某些特徵的某一端，而在這個
標的池裡因子傾斜本身就賺錢。隨機抽籤沒有任何傾斜。

### 毛報酬的解剖

```
持有全池              2.45%
隨機 10 檔（中位）     2.14%
任意函數取前 10        3.95%    ← +1.50 pp 來自「集中選股」本身
手工分數取前 10        4.56%    ← 再 +0.61 pp
模型取前 10           4.62%    ← 再 +0.67 pp
```

**模型對隨機的 2.48 pp 總優勢裡，1.81 pp（73%）來自集中化的因子傾斜，
不是來自預測。**

### 順帶：隨機中位數本身也偏低

隨機 10 檔的毛報酬（2.14%）**低於**持有全池（2.45%）。報酬分布右偏，
200 次抽樣的**中位數**低於全池的**平均數**。

所以「隨機進場取中位數」有兩個獨立的偏低來源：沒有因子傾斜、取中位數。
兩者都讓門檻變低。

## 換成正確的虛無假設，兩個訊號都不通過

```
配對比較         差異      標準誤     t     判定
真模型 − 隨機   +2.58%   1.01%   2.56   顯著較好    ← 錯的門檻
打亂   − 隨機   +1.88%   0.81%   2.32   顯著較好    ← 證明門檻錯了
真模型 − 打亂   +0.70%   1.29%   0.54   量不出差別   ← 真正的預測貢獻
真模型 − 手工   +0.16%   2.17%   0.07   量不出差別
手工   − 打亂   +0.54%   1.55%   0.35   量不出差別
```

**LightGBM 與手工分數無法區分（t = 0.07），而兩者對正確虛無假設都
量不出優勢。**

## 這推翻的不只是這次

CLAUDE.md「必跑對照組」規定：

```
- 等權買進持有（同一標的池）
- 0050 買進持有
- 隨機進場（100 次模擬取中位數）
```

**第三項對任何基於因子的策略都太低。**

所以先前那句結論也被弱化了：

> 樣本外 +138.83%，**超過隨機 95% 分位 +120.97%**，但輸 0050 買進持有

超過隨機 95% 分位這件事，**一個標籤打亂的模型很可能也做得到**。
那份 OOS 報告的其他結論（輸 0050）不變，但「超過隨機」不再構成證據。

## 兩個補充觀察

### 模型在重新發現動能，但選不同的名字

特徵重要度（gain 累計）：

```
momentum_120          13.3%
margin_to_volume_20   11.5%
true_range_ratio_14   10.7%
short_margin_ratio     9.9%
momentum_60            7.8%
trust_net_ratio_20     7.8%
ma_ratio_60            5.9%
foreign_net_ratio_20   5.8%
margin_change_20       5.7%
momentum_20            2.9%
```

長期動能排第一，`ma_ratio_60`、`momentum_60` 也在前段——**模型確實在
重新發現動能**。

但前 10 檔與手工分數的重疊：

```
中位 1 檔   平均 1.1 檔   完全不重疊 11/36 期
```

**兩者同意「哪個因子」，卻不同意「哪些名字」。** 那正是「有因子傾斜、
沒有個股層級技能」的樣子——如果任一方真的分辨得出個股，重疊會高得多。

### DSR 1.0000 毫無意義

```
DSR 1.0000   運氣門檻 0.0000   有效觀測 54   試驗 1
```

`n_trials = 1` 時期望最佳 Sharpe 退化為 0（沒有選擇偏誤可扣），
**DSR 只是在檢定「Sharpe > 0」**。

它只說明「沒有掃參數」，不說明訊號有用。這與先前那次
`sharpe_std` 用預設 1.0 是同一類問題：**統計量的輸入決定它在說什麼，
而預設值往往什麼都沒說。**

## 對規格的影響

必跑對照組要加第四項。見 `taiwan-quant/CLAUDE.md` 的修訂。

```
模型類策略   打亂標籤後重訓，取前 N 檔
分數類策略   同一特徵集的隨機權重組合，取前 N 檔
```

兩者的共同性質：**與策略有相同的結構（集中、基於特徵、時間上持續），
但與標籤沒有預測關係。**

⚠️ 本次驗證的是模型版（打亂標籤）。分數版（隨機權重組合）是邏輯上的
對應物，**尚未實測**。
