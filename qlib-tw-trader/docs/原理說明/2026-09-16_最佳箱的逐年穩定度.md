# 最佳箱的逐年穩定度

- 日期：2026-09-16
- 對應程式：`scripts/diagnose_bin_stability.py`
- 原始輸出：`taiwan-quant/reports/bin_stability_dev_h60.txt`
- 前置：`2026-09-16_箱內排序能力與優勢集中度.md`

---

## 要回答的問題

上一份診斷發現三族的優勢都擠在一個薄箱，動能突破的 7.53% 是 1,597 個
樣本算出來的（箱內 t 值只有 0.18）。

**那是真的，還是少數幾年撐起來的？**

## 為什麼看超額不看絕對報酬

2020~2021 是大多頭，任何箱的絕對報酬都好看；2022 是空頭，全部難看。
直接比絕對報酬只會量到市場方向。所以主要看：

```
超額 = 該箱當年平均報酬 − 當年**所有候選**的平均報酬
```

---

## 結果：三族各有各的問題，沒有一族全過

| 判準 | 動能突破 | 籌碼跟隨 | 均值回歸 |
|---|---|---|---|
| 超額為正的年數 | 6 / 8 ✅ | **7 / 8** ✅ | 4 / 8 ❌ |
| 拿掉最好那年仍 > 成本 1.271% | +2.01 pp ✅ | +0.14 pp ❌ | +2.23 pp ✅ |
| 不靠單一年份 | ✅ | ✅ | ❌ |

```
動能突破   優勢真實，但 2023 單年 −6.98 pp
籌碼跟隨   最穩定（7/8 年正），但幅度只有成本的五分之一
均值回歸   全靠 2020~2021，4/8 年為正等於擲硬幣
```

## 逐年明細

### 動能突破（箱 0）

```
年份    該箱樣本    該箱報酬    全體候選     超額
2016      192       8.66%      3.34%     +5.32 pp
2017       69       2.86%      3.21%     −0.35 pp
2018      379       0.19%     −0.11%     +0.30 pp
2019       87       6.39%      2.71%     +3.68 pp
2020      330      23.58%      6.40%    +17.18 pp   ← 最好的一年
2021      142       9.68%      3.68%     +6.00 pp
2022      347       1.42%     −0.38%     +1.80 pp
2023       51      −2.16%      4.82%     −6.98 pp   ← 最後一年轉負

加權平均超額  +5.15 pp    拿掉 2020 後  +2.01 pp
前半 2016~2019 +1.97 pp   後半 2020~2023 +7.80 pp
```

**拿掉最好的一年後仍有 +2.01 pp，高於來回成本 1.271%。** 這一族的優勢
不是單一年份撐起來的。

### 籌碼跟隨（箱 3）

```
2016 +0.04｜2017 +0.76｜2018 +0.31｜2019 −0.59
2020 +1.07｜2021 +0.02｜2022 +0.21｜2023 +0.27     （pp）

加權平均超額  +0.26 pp    拿掉 2020 後  +0.14 pp
```

**7/8 年為正——三族裡最穩定的。但幅度只有 0.26 pp，成本是 1.271%。**

方向對，力道不夠。這與上一份診斷的 `has_discrimination = False`
（箱間全距 0.54 pp < 1.071%）是同一件事的兩種量法。

### 均值回歸（箱 5）

```
2016 −0.15｜2017 +1.60｜2018 −0.08｜2019 −1.70
2020 +9.77｜2021 +12.90｜2022 +3.52｜2023 −0.88   （pp）

加權平均超額  +4.19 pp    拿掉 2021 後  +2.23 pp
前半 2016~2019 −0.15 pp   後半 2020~2023 +7.89 pp
```

前半期超額是**負的**。整族的優勢完全來自 2020~2021——疫情後的極端行情。
4/8 年為正等於擲硬幣。

## 我目測錯了一次，工具糾正了

看到動能突破的 2019→2023 是 `+3.68 → +17.18 → +6.00 → +1.80 → −6.98`，
我直覺說「單調遞減，優勢在衰退」。

加了前後期對比之後：

```
前半 2016~2019   +1.97 pp
後半 2020~2023   +7.80 pp     ← 上升，不是衰退
```

**我漏看了 2016~2018。** 只挑後面五年看，就會把一個上升的序列讀成下降。

2023 的 −6.98 pp 仍然值得注意（它最接近尚未使用的評估區間），但那是
**單年**，不是趨勢。這兩件事必須分開講。

⚠️ 教訓：目測時序容易只看最近幾個點。前後期對比是很便宜的糾錯機制，
**而且這次它推翻的是我自己的假設**。

## 對下一步的意義

上一份診斷列了三個提高排序解析度的方向，第 3 個（排序改用原始分數）
已被箱內 IC = 0 否定。這份結果對另外兩個也有話說：

| 方向 | 這份結果怎麼說 |
|---|---|
| 提高 `CALIBRATION_BINS` | 動能突破箱 0 只有 1,597 樣本、每期 4.3 檔。**再切細只會讓它更薄** |
| 換連續模型 | 仍然可行，但要先問特徵裡有沒有資訊 |

**真正該問的不是「怎麼排得更細」，是「怎麼讓有優勢的候選變多」。**

動能突破每期只有 4.3 檔落在最佳箱，Top 3 幾乎全部來自那裡——所以路徑
變異大。提高那個箱的候選密度，比提高全體排序解析度更直接。

具體可試的（都在開發集做）：

```
1. 放寬標的池到 200~300 檔    箱 0 的絕對檔數會等比例增加
2. 縮短決策間隔               每期候選不變，但決策次數變多
3. 拉長持有期到 120 日        成本降到 2.65%/年，薄箱的優勢更容易存活
```

第 3 個最便宜且有現成數字支撐（CLAUDE.md 的持有期表），而且不動策略參數。

## 限制

⚠️ 用**全樣本擬合**的校準器（不切分）。要問的是「這個箱的優勢在時間上
穩不穩」這個結構性問題，**這些數字不是樣本外結論**。

⚠️ 均值回歸的箱 5 每年只有 37~116 個樣本，單年平均本身就很不穩。
2021 的 +12.90 pp 是 116 個樣本算出來的。
