## 二、為什麼 0050 是比等權更嚴格的對照

CLAUDE.md 明訂「0050 買進持有」是必跑對照，但前五輪都缺席——
上游資料庫不含 ETF。長歷史回補後 0050 / 0051 / 0056 都有完整 11 年
資料，這個缺口沒有理由再留著。

```
等權持有 150 檔   每季調倉、付 150 次交易成本
0050             買一次就好
```

**它是可以真的買到的東西。** 策略連它都贏不了，就沒有存在的理由。

### 四個對照的排序本身就是資料品質的旁證

```
等權買進持有   +701.37%   MaxDD 33.68%
0050 台灣50    +618.34%   MaxDD 33.83%
0051 中型100   +528.94%   MaxDD 31.30%
0056 高股息    +306.31%   MaxDD 26.89%
```

等權 > 大型 > 中型 > 高股息，回撤則高股息最小。符合直覺，而且不是
我調出來的——這是獨立資料算出來的結果。

### 實作上的兩個決定

**一、等權對照不可把 ETF 算進去。** ETF 本身就是一籃子，混進等權
組合等於重複計入成分股。

**二、資料不足的 ETF 直接略過，不放進結果。** 回一條空的或全 1 的
曲線會被誤讀成「那檔剛好沒漲跌」。

## 三、下市股票的還原價

### 問題

yfinance 查不到已下市的股票——107 檔沒有還原價。而下市股票正是
survivorship 的關鍵樣本（2015 年標的池裡的日月光、矽品都已下市）。

因為拿不到還原價就排除它們，等於把好不容易解掉的 survivorship bias
又放回來。

### 解法：官方除權息紀錄

FinMind 的 `TaiwanStockDividendResult` 免費層可用，且對下市股票也有
紀錄。直接給：

```
before_price   除權息前收盤價
after_price    除權息參考價
factor = after_price / before_price
```

向後還原（back-adjustment）：

```
adj_close(t) = close(t) × Π { factor(e) : e.date > t }
```

**除權息日當天的價格已經是除息後的價格**，所以只有嚴格早於事件日的
價格需要乘上因子。方向反了會讓報酬率整段偏掉，而曲線看起來仍然正常。

### 兩道邊界檢查

```
前收 / 參考價必須為正      除以 0 得到 inf，而 inf 不會讓比較拋錯
因子必須落在 [0.5, 1.5]   離 1 太遠代表資料有問題
```

台股單次除權息很少讓參考價低於前收的一半。超出範圍時拋錯而不是照用——
資料錯誤比漏一次除息嚴重得多。

### 驗證：反而發現 yfinance 比較髒

與 yfinance 比對 6 檔，2317 與 2881 差很多。查因子的變動日：

```
2317  除權息法   12 個變動日，全部是真實除息日
      yfinance   42 個變動日，含 2016-08-22 ~ 09-13 的連續段
```

那段連續變動不是公司行為。**除權息法只在官方除息日變動，方法學上
更乾淨。**

### 但只補缺口，不覆寫

既有的 yfinance 還原價已與 qlib-tw-trader 的 production 資料驗證過
（中位誤差 2e-6）。覆寫會讓先前所有的驗證結論不可比。

代價是資料庫混了兩種方法（1,111 檔 yfinance + 107 檔除權息推算），
必須隨報告揭露。

## 四、最重要的發現：還原因子的缺漏處理錯了

### 怎麼被發現的

0050 的最大回撤算出 **84.20%**。2019-2026 之間台股沒有這種跌幅——
2022 年台積電也只跌約 50%。**數字不合理就先懷疑程式。**

### 根因

0050 在 2025-06-18 做了 **1:4 分割**（188.65 → 47.57）。還原價正確
處理了它，但有 11 天缺還原價。而原本的做法是：

```python
# 不可用的列因子設為 1.0，等於保留原值
safe_factor = factor.where(usable, 1.0)
```

於是那些天的價格留在**分割前的尺度**：

```
2021-04-06   原始 137.65（被保留）
鄰近日        還原後約 33.5
→ 單日 4 倍尖峰 → 假回撤 84.20%
```

### 正確做法：補**因子**，不是補價格

還原因子在兩次公司行為之間是**常數**。所以缺值時應沿用前一個已知
因子（序列開頭則用之後的第一個）：

```python
factor = factor.groupby(stock_id).ffill()
factor = factor.groupby(stock_id).bfill()
safe_factor = factor.fillna(1.0)   # 整檔都沒有還原價時才保留原價
```

**分標的補。** 跨標的外溢會讓另一檔的價格整段偏掉。

`is_adjusted` 仍然只標記**原生**有還原價的列，讓報告分得出哪些是
查來的、哪些是推的。

### 修正前後

```
          修正前     修正後
0050      84.20%    33.83%
0051      40.39%    31.30%
0056      54.13%    26.89%
等權       47.05%    33.68%
```

### 這個 bug 的性質

它不拋任何錯，只會讓任何有缺還原價日的標的在還原序列裡出現尖峰。

**沒有分割的股票因子接近 1，尖峰只有 20% 上下，看起來像正常波動。**
只有 0050 這種做過 4:1 分割的才暴露出來。

先前五輪驗證的回撤數字都受它影響。

## 五、標的池代理：從 72.7% 到 94.7%

### 怎麼驗證一個代理

歷史成分股取不到，但**現況可以**。拿今天真實的 0050+0051 名單
（元大官網，150 檔）去比對代理的最新快照——這是唯一能檢驗代理品質的
方式。

### 第一版：成交金額排名

```
命中 109 / 150 = 72.7%
漏掉：1102 亞泥、1402 遠東新、1503 士電、2002 中鋼、2105 正新、2207 和泰車
```

全是**大市值但低週轉的傳產**。成交金額排名系統性偏向熱門股，而
0050 / 0051 是市值加權指數，正好相反。

### 第二版：市值排名

TWSE `MI_QFIIS`（外資及陸資持股統計）的「發行股數」欄位支援任意
歷史日期。每季一次、47 個請求就覆蓋 11 年：

```
市值 = 當日收盤價 × 發行股數
```

```
命中 142 / 150 = 94.7%
```

### 組成的差異看得出來

```
          2018 年的前六名
市值版     台積電、鴻海、中華電、台塑化、台塑、南亞      ← 權值股
成交金額版  台積電、國巨、華新科、玉晶光、鴻海           ← 當年的熱門股
```

歷來成員也從 586 檔降到 **280 檔**——市值排名穩定得多。

### 兩種排名並存

`universe_history` 表加上 `basis` 欄位，兩份快照同時保留：

1. 可以直接比較兩種代理對真實成分股的命中率
2. `04` 與 `05` 的驗證結果是用 turnover 版跑的，刪掉就無法重現

`load_universe_at()` 預設取 `market_cap`。

### 接線時踩到的坑

`validate_oos_trailing.py` 的 `all_members` 還在查舊表，於是市值版
獨有的 **31 檔**不會被載入價格，會在候選清單裡靜默消失。

**凡是有兩個資料來源的地方，都要確認它們查的是同一個。**

### 仍然是代理

真實指數還有流動性門檻、產業分散、自由流通量調整，而且成分股審核
每季由指數公司人工核定。真實的歷史成分股在免費來源取不到——元大只
公布現況，指數公司的歷史審核公告沒有 API。
