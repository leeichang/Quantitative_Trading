## 必須先更正的數字

那份文件把「訊號能預測漲停」列為 **✅ 成立**，依據是：

```
基準（隨機一檔）   2.47%
動能突破 Top 3    16.62%      6.7 倍
```

**這兩個數字都高估了。** 同期間（2019-01 ~ 2023-12）、同選法
（Top 3 橫斷面每日）、時點標的池，重新用有測試的程式量：

```
指標              原始宣稱    本次實測    高估倍數
全池 5 日漲停率     2.47%     0.98%      2.5 倍
Top 3 5 日漲停率   16.62%     4.52%      3.7 倍
倍數                6.7x      4.6x
```

**方向成立，量級不成立。** 4.6 倍仍然是真的預測力，但絕對命中率只有
原本宣稱的四分之一到三分之一。

### 為什麼差這麼多

原始那份分析**沒有留下程式**，所以無法反查。但漲停次數的差異指向門檻：

```
2019~2023 漲停次數    原始 2,165    本次 1,076
```

而全庫日報酬的分布顯示門檻放寬多少就多算多少：

```
報酬 >= 0.0995   11,086 筆
報酬 >= 0.096    32,043 筆      ← 3 倍
```

最可能是原始版本用了一個較鬆的門檻（例如 `>= 0.09`），把「接近漲停但
沒鎖上」的日子也算進去。

**這正是為什麼要把它寫成有測試的模組。** 一個沒有測試的臨時計算，
下次重跑不保證得到同一個數字——而這次就沒有。

## 判定方式：依跳動單位精算，不用容差

漲停價是 `參考價 × 1.1` 依跳動單位**向下**取整，所以實際漲幅通常低於
10%：

```
參考價     ×1.1      跳動    漲停價      實際漲幅
790.00    869.00    1.00    869.00     +10.0000%
 27.90     30.69    0.05     30.65      +9.8566%
  9.99     10.989   0.05     10.95      +9.6096%   ← 最壞情況（跨價格帶）
 45.50     50.05    0.10     50.00      +9.8901%
910.00   1001.00    5.00   1000.00      +9.8901%
```

第一版用一個 0.4 pp 的「容差」處理這件事。實測最壞折讓是 0.39 pp，
所以那個容差剛好對——**但它剛好壓在邊界上**，而且它是一個要辯護的
參數。跳動單位是公告規則，用它精算就不需要容差。

### 寫容差版時我的測試案例是編錯的

當時寫「790 元的漲停價是 865，漲幅 9.49%」。**790 元的跳動單位是 1 元，
漲停價是 869（+10.00%）。** 865 是憑空的。

那個錯誤讓測試失敗，才逼出「不要用容差，直接算」。

## 為什麼用還原價

直覺會說「±10% 是對**實際報價**的限制，所以要用未還原價」。實際相反：
交易所在除權息日也會調整參考價，所以還原後的報酬才是限制實際適用的
對象。

實測（2015-06 起，2.8M 筆日報酬）兩者都有超過 10% 的殘留：

```
報酬區間          未還原價    還原價
[0.100, 0.105)     2,879     2,399
[0.105, 0.200)     1,359     1,057
```

還原價少一些（現金減資會把未還原的參考價往上調，看起來像暴漲），
但**沒有消掉**——IPO 首日與長期停牌後恢復交易沒有漲跌幅限制。
那些不是判定錯誤，是真的沒有上限的日子。

## 分位桶：極端值才有資訊，而且時點安全版更陡

原始那份的分桶用**全期分位**，那是 look-ahead——等於先知道整段歷史的
分數範圍。用擴張視窗（只用 ≤ t 的分數）重算：

```
分位桶        觀察數      5 日漲停率
0%~50%      104,904        0.83%
50%~80%      64,129        0.62%   ← 比最低 50% 還差
80%~90%      20,978        1.01%
90%~95%       9,918        1.79%
95%~98%       5,716        3.59%
98%~99%       1,863        5.64%
99%~100%      1,754        8.38%   ← 只有這一段明顯
```

**「不是單調的」這個結論成立**，而且時點安全版的最高桶（8.38%）比
Top 3 橫斷面（4.52%）更陡——「歷史上罕見的高分」比「今天最高分」
更有資訊。

### 週頻（H=5）明確為負

```
q=0.99, H=5   命中率 6.3%   命中時毛 +8.80%   沒命中時毛 −0.66%
              加權毛 −0.06%   成本 0.865%   淨 −0.93%/趟
              年化 −18.1%   MaxDD −76.2%
```

**221 筆交易，每筆淨 −0.93%，複利下來就是 −87%。** 這不是崩盤，
是成本一點一點流掉。

先前我估「降成本後大約 +2.9% 年化，貼在損益兩平線上」。**那個估計
偏樂觀**，因為它用了原始那個被高估的命中率，而且把兩個不同樣本
（最高 1% 分位的所有名字 vs N=3 取前三名）混在一起。

實測是 **−18.1%**，不是 +2.9%。

### 沒有任何一格贏得過「一直在市」

```
事件驅動最佳格   年化 +12.0%   MaxDD −48.1%
動能突破 N=10 一直在市（同開發集）  年化 +22.2%
0050 買進持有（OOS 區間）          +242.15%
```

**空手等訊號的代價比省下的成本大。** 資金投入只有 23~87%，而空手那段
的機會成本沒有被任何東西補回來。

### 持有期越長越好，而且是單調的

```
q=0.99   H=5    −0.93%/趟   年化 −18.1%
         H=10   +0.77%      年化  +7.6%
         H=20   +1.79%      年化 +10.2%
         H=40   +3.49%      年化 +10.0%
```

這與 CLAUDE.md「持有期不得低於 60 個交易日」同一個方向。
**漲停命中率隨 H 上升（6.3% → 25.4%）只是因為視窗變長、機會變多**，
不是預測變準。

### 漲停鎖死幾乎不影響

12 格裡被「進場日鎖死買不到」擋掉的只有 0~2 筆。原始那份說鎖死佔
漲停的 4.7%，但那是**漲停當天**；我們是在訊號出現的隔天進場，
那天鎖死的機率低得多。

## 對使用者問題的直接回答

「每週抓一檔漲停、40 週複利 45 倍」這條路，現在有完整的實測拆解：

```
1. 訊號能預測漲停嗎          能。4.6 倍（不是原本說的 6.7 倍）
2. 命中率多高                q=0.99 H=5 時 6.3%
3. 命中時賺多少              +8.80% 毛（不是 +10%——漲停是某一天 +10%）
4. 沒命中時賠多少            −0.66% 毛
5. 加權後                    −0.06% 毛
6. 扣成本（已壓到地板）       −0.93% 淨/趟
7. 年化                      −18.1%
```

**第 5 步就已經是負的了，成本只是讓它更負。** 問題不在成本，
在於 6.3% 的命中率乘上 8.8% 的獎賞，抵不過 93.7% 的機率損失 0.66%。

而 40 週複利 45 倍的前提是**每週都命中**。6.3% 到 100% 不是努力的距離。
