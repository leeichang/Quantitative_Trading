# 訊號是真的，但 40 萬吃不到：容量、加碼、持有期、新聞四條路都試過了

- 日期：2026-09-19（量測於 2026-09-18 深夜）
- 起點：使用者問「你先前說的 +16,094 元／年，我實際能拿到嗎？」
- 對應程式：`taiwan_quant/validation/event_study.py`（`capacity_constrained_fills`）
- 前置：`2026-09-18_融資暴增之後的超額報酬.md`（全抓的 +1.709%／趟、t=5.21）
- 測試：1,022 passed

---

## 先講結論

**融資暴增的訊號是真的（t=5.21，過 Bonferroni）。但 40 萬拿不到它。**

我先前報給使用者的 **+16,094 元／年是錯的**，錯在對使用者不利的方向：
那是「全抓 108 檔」的數字，而 40 萬只能持有 20 檔。

修正後的數字，以及四條想救回來的路，全部在下面。**四條都失敗。**

---

## 一、全抓不是 100%，連無限資金也只有 37.4%

```
可吃 3,250 筆
吃下 1,214 筆（位子無限）
位子滿而錯過      0 筆
已持有而跳過  2,036 筆  ← 62.6%
```

**62.6% 的事件是同一檔在 40 天內重複觸發。** 買第二次是加碼不是分散，
所以跳過。這與資金無關——**無限資金也只吃得到 37.4%。**

我在 `10_前推驗證的預先登錄_融資暴增.md` 把這列為預期失敗模式
（「2884 在 7 個交易日內觸發 3 次」），現在量出來了。

---

## 二、40 萬的實際淨值：20 個位子是負的

每檔最低 2 萬（低於此零股成本吃掉期望值）→ 40 萬上限 20 檔。

```
位子    毛超額              95% 區間     成本/趟     淨/趟      年化
 10  +1.558%  [+0.002%, +3.124%]   1.081%  +0.477%   +3.04%
 20  +1.171%  [+0.063%, +2.310%]   1.194%  −0.023%   −0.15%
 50  +0.844%  [−0.015%, +1.718%]   1.194%  −0.350%   −2.19%
```

**20 個位子的淨值是負的。** 10 個位子（每檔 4 萬）最好：

```
            年化      40 萬一年
點估計     +3.04%     +12,173 元
區間下界   −6.61%     −26,425 元
區間上界  +13.59%     +54,354 元
```

點估計 +12,173 元，**而區間包含 −26,425 元**。

### 抓取率

```
事件密度 2.7 檔/日，H=40
位子 10 → 每日可開 0.25 個新倉 → 抓 11.1%
位子 20 → 每日可開 0.50 個新倉 → 抓 21.4%
```

隨機取子集不影響**期望**超額，但 20 檔對 108 檔，變異約 2.3 倍。
**實際年度結果主要由運氣決定。**

## 三、依分數挑，比隨機挑更差

```
分數高者優先   +1.171%
隨機順序       +1.340%（5 個種子 +1.016% ~ +1.668%）
→ 依分數挑    −0.169%
```

三次量測有兩次隨機較好（另兩次是 −0.471%、−0.798%）。

**沒有證據顯示融資暴增的分數能排序事件品質，弱證據顯示它有害。**
`record_forward_events.py` 目前照分數排 `rank`，那個排序沒有價值——
但也不該現在改成隨機，因為那是看到結果之後的調整。

## 四、四條救援路徑，全部失敗

### 路徑 1：允許加碼（不跳過重複觸發）

`capacity_constrained_fills(allow_repeat=True)`：

```
H=40  跳過  吃下 360  自擋 25.0%  年化 +3.04%
H=40  加碼  吃下 360  自擋  0.0%  年化 +3.87%
```

**吃下的數量完全一樣（360）。**

因為 **10 個位子時瓶頸是位子，不是自擋。** 解除自擋只是換成別的名字
填同樣 360 個位子。我先前說「62.6% 的損失來自重複觸發」對，
**但只在無限位子下成立**——在使用者的規模上那不是瓶頸。

年化在其他持有期上方向不一致（H=60 是 +10.83% vs +0.13%，
H=30 是 +2.85% vs −5.03%）。**雜訊。**

### 路徑 2：拉長持有期

```
 H    毛超額     淨/趟      年化          年化區間
 40  +1.558%  +0.477%   +3.04%  [ −6.65%, +13.80%]
 60  +3.569%  +2.478%  +10.83%  [ −1.00%, +24.15%]   ← 尖峰
 80  +1.440%  +0.373%   +1.18%  [ −9.67%, +13.96%]   ← 塌掉
100  +2.840%  +1.759%   +4.49%  [ −6.30%, +16.69%]
120  +2.318%  +1.215%   +2.57%  [ −7.93%, +15.22%]
```

H=5 到 60 確實單調上升（−30.77% → −17.35% → −11.72% → −3.82% →
+2.85% → +3.04% → +10.83%），**但 H=80 掉回 +1.18%。**

非單調。與 `cost_floor_dev.json` 的毛報酬在 H=80 塌掉是同一個形狀，
而那個形狀在 2026-09-18 已經被判定為雜訊。

⚠️ **每一格的區間都包含零。** 沒有任何持有期能把淨值與零區分開。

事件日數隨 H 崩掉：290 → 180 → 132 → 106 → 96。

### 路徑 3：新聞（用機械足跡，不是爬文字）

2026-09-17 的結論「新聞在落地當天就被定價」用的基準是全期漂移、
沒有標準誤、樣本單位是股票-事件、只測 H=20。用今天的框架重跑：

```
事件              H=20      H=40      H=60     H=120
漲>7% 量>5倍    −1.629%   −1.414%   −2.119%   −3.993%
漲>5% 量>3倍    −0.406%   +0.061%   +0.276%   −1.592%
漲>5% 外資>3倍  −0.849%   −0.391%   −0.558%   −0.646%
跌>5% 量>3倍    +0.351%   +0.950%   +2.612%   +6.202%
```

**16 格，Gumbel 門檻 |t| > 2.35，零格通過。** 每一格區間都含零。

但方向比顯著性有訊息：**大漲爆量之後回吐，大跌爆量之後回升**，
兩邊互為鏡像、四個持有期一致。那是量能衝擊後的均值回歸，
**不是新聞的延續效應**。

#### 使用者的假說有一半是對的

```
事件當天平均漲幅        +7.67%   ← 比我測過的任何東西都大
T+1 開盤的跳空          +0.67%   ← 收盤才知道，也拿不到
T+1 開盤起算 60 日超額   +0.276%   t=+0.34
來回成本                1.081%
```

**新聞的影響確實最大。但 +7.67% 在能下單之前就結束了。**
盤後決策、隔日進場，結構上不可能快過市場。

#### 爬新聞文字的那道牆

技術上可行。但**回測不誠實**，而且不是資料問題：

> 讀 2018 年的新聞時，已經知道 2019 年發生了什麼。

那是詮釋層的 look-ahead，**沒有任何程式能檢查**。機械足跡繞開整道牆，
因為它們是有乾淨時戳的數字。

唯一誠實的用法是**只往前收集，不回測**——和前推帳本一樣要等。

### 路徑 4：（未做）放寬或收緊事件門檻

`QUANTILE = 0.99` 固定，沒掃過。

⚠️ **放寬不會幫忙**，因為瓶頸是位子不是訊號：99 分位已經是 2.7 檔/日，
而 10 個位子每天只吃 0.25 檔。反過來**收緊到 99.5 可能更好**
（事件更少但更強，配合容量）。

**這條沒測，寫進工作單 11。**

## 五、一個我要承認的規格違反

`CLAUDE.md` 第 423 行：

> **任何新策略的持有期不得低於 60 個交易日**，除非能證明每趟毛報酬
> 顯著高於 1.84%。

**我選 H=40 是因為原始事件網格只跑到 40，不是因為它合規。**
而 `10_前推驗證的預先登錄_融資暴介.md` 把 H=40 鎖住了——
**那份登錄本身違反既有規格。**

⚠️ **但不在此刻改成 H=60。** 我剛看到 H=60 在掃描裡贏，此刻把它加進
帳本就是事後挑格子——即使 CLAUDE.md 獨立地指定了 ≥60，時序上已被污染。

三個選項留給使用者決定，寫進工作單 11。

## 六、多重測試的帳已經很難看

今天在容量受限這條線上測的格子：

```
位子 × 持有期      7 × 2 = 14 格（加碼 vs 跳過）
持有期延伸         5 格（H=40/60/80/100/120）
新聞足跡           16 格（4 事件 × 4 持有期）
位子掃描           7 格
```

加上原始事件網格的 20 格，**今日累計約 62 格**。

Gumbel 門檻 √(2 ln 62) = **2.87**。融資暴增全抓的 t=5.21 仍然過，
但任何 t < 2.87 的格子都不能當發現——**包含 H=60 的那一格**。

## 結論：訊號真，但不可收割

```
✓ 融資暴增的橫斷面超額是真的        t=5.21，過 Bonferroni，已排除動能與 look-ahead
✗ 40 萬吃不到                      20 位子淨值為負，10 位子區間含零
✗ 加碼救不回來                      位子才是瓶頸
✗ 拉長持有期救不回來                H=80 塌掉，全部含零
✗ 新聞救不回來                      16 格零通過，當天那段拿不到
```

**我不建議現在投入 40 萬。** 訊號不是假的，是**在這個規模上收割不了**。

前推帳本繼續記是對的（零成本、累積證據），把錢放進去沒有證據支持。

## 還沒試過的

```
□ 事件門檻掃描（99.0 / 99.5 / 99.8）——瓶頸是位子，所以收緊可能更好
□ 外資買超極端的負超額（四個持有期全為負，H=10 時 t=−1.94）
□ 跌>5% 量>3倍 的均值回歸（H=120 淨 +5.121%，但 t=1.62，門檻 2.87）
□ 成本結構本身：N=3 整股（成本 0.834%）vs N=10 零股（1.081%）
  整股讓同一個訊號的區間不含零（見下）
```

### 最後一個數字，它指出唯一的方向

同一個訊號（全抓，毛 +1.709%，區間 [+1.051%, +2.379%]），只換成本：

```
成本/趟                  淨/趟      年化           年化區間      含零?
零股個股 1.081%（實測）   +0.628%   +4.02%  [−0.19%,  +8.46%]   含零
整股個股 0.671%（實測）   +1.038%   +6.72%  [+2.42%, +11.26%]   不含零
```

**訊號沒變，變的是成本。整股就不含零了。**

所以真正的約束不是「台股不能預測」，而是：

> **40 萬 ÷ 10 檔 = 4 萬/檔 = 被迫零股 = 1.081% = 吃掉一個真實的訊號。**

那是「小資金 × 個股 × 零股」這個組合的問題。**下一輪該攻的是成本
結構，不是再找訊號。**
