
⚠️ **我不建議現在投入 40 萬做高周轉策略。** 理由在第三節。

## 二、找到的東西

### 2-1. 融資暴增之後有超額報酬（唯一通過多重測試的正向結果）

相對**同一天全池平均**的超額(大盤共同變動已消掉):

```
事件        H    事件數   日數      超額      SE       t     判定
融資暴增    40   3179   1172  +1.709%  0.328%  +5.21  過 Bonferroni
融資暴增    10   3231   1196  +0.600%  0.139%  +4.32  過 Bonferroni
融資暴增    20   3213   1189  +0.793%  0.194%  +4.10  過 Bonferroni
融資暴增     5   3237   1200  +0.306%  0.103%  +2.98  過 Gumbel
漲停        40    469    320  +3.123%  1.476%  +2.12  未過
```

**三個 confound 都排除了:**

- **不是動能** —— 當天下跌的子集效應最大(+2.226%,t=4.42),與漲停只重疊 2.65%
- **沒有 look-ahead** —— 用恆等式 `balance[T] = balance[T−1] + buy − sell` 驗證資料對齊,2330 在 2023-06 的 19 個交易日全部成立
- **跳空算進成本** —— 用 T+1 開盤進場;排除一價到底(買不到)後結果幾乎不變

依據:`2026-09-18_融資暴增之後的超額報酬.md`

### 2-2. 低周轉移除成本約束（最後一天的發現）

```
同一個 1.071% 的來回成本
事件策略 H=40   每年 6.30 趟  →  年化拖累 6.75%
買進持有 9 年   進出各一次    →  年化拖累 0.06 ~ 0.11%
```

**差 60~100 倍。** 主宰本週每一個結論的約束,在低周轉下基本消失。

⚠️ 但報酬面仍然量不出來:五個進場年份的九年持有期互相重疊,**有效樣本
接近 1**。成本的優勢是算術(確定),報酬的優勢不是。

依據:`2026-09-19_低周轉移除了成本約束.md`

### 2-3. 一個反直覺的副產品

**外資買超極端之後是負超額**(四個持有期全為負,H=10 時 t=−1.94)。

## 三、為什麼 40 萬吃不到那個訊號

這是本週最重要的推導。

```
事件密度 2.7 檔/日 × 持有 40 天 = 穩態需要 108 檔同時持有
40 萬 ÷ 108 = 3,687 元/檔  ← 低於零股成本地板

每檔最低 2 萬 → 40 萬上限 20 檔
20 檔 ÷ 40 天 = 每天可開 0.5 個新倉，而事件有 2.7 個
→ 必須放掉 81.6%
```

實測(⚠️ 這些數字後來被標記作廢,見第五節):

```
位子   毛超額    成本/趟    淨/趟     年化
 10   +1.558%   1.081%  +0.477%   +3.04%   區間 [−6.61%, +13.59%]
 20   +1.171%   1.194%  −0.023%   −0.15%   ← 負的
```

**四條救援路徑全部失敗:**

```
✗ 加碼（允許重複觸發）   位子才是瓶頸，吃下的數量完全一樣（360）
✗ 拉長持有期            H=60 是尖峰，H=80 塌回 +1.18%，全部含零
✗ 新聞                  16 格零通過；當天 +7.67% 在能下單前就結束
✗ 放寬事件門檻          瓶頸是位子不是訊號
```

### 而真正的約束在這裡

```
4 萬元零股單的來回成本 1.071% 拆開
手續費 × 2     0.171%   法定上限 × 6 折，可談到 0.08%
證交稅         0.300%   法定，股票不可減（ETF 0.1%、當沖 0.15%）
滑價 × 2       0.600%   ← 最大項，而且是唯一沒有量測的一項
```

`config/costs.py` 的滑價是兩段式:零股 0.3%／0.4%(禁令 4 明文規格,
**無量測**)、整股 0.1%(**有 490 筆實證**)。

實測 264 檔真實收盤價:

```
每檔金額       模型                滑價中位   來回成本
133,333       舊：兩段式（整股）    0.1000%   0.6710%
133,333       新：跳動單位 × 1.0    0.1051%   0.6812%   ← 幾乎一致
 40,000       舊：兩段式（零股）    0.3000%   1.0710%
 40,000       新：跳動單位 × 2.0    0.1602%   0.7914%
 40,000       新：跳動單位 × 3.0    0.2186%   0.9083%
```

**新模型重現了唯一有量測的那個數字。** 而零股那個沒量測的 0.3%,
比「3 倍跳動單位」還高。

⚠️ **訊號的區間在成本 ≤ 0.871% 時不含零,而倍數 2.0 是 0.7914%。**
所以「吃不到」可能部分是一個未驗證參數的產物。**但我不宣稱反面** ——
訊號本身有污染(第五節)、2.0 倍也沒量測、而且是開發集。

依據:`2026-09-19_訊號是真的但40萬吃不到.md`、`2026-09-19_低周轉移除了成本約束.md`

## 五、我這週做錯的事（最有價值的一節）

**18 個 bug 裡大部分是「讓結果變好看」的方向。** 逐項列出,因為
每一個都代表一類會再犯的錯。

### 5-1. 持有期多算一天，推翻了我自己的主要發現

三個檔案寫 `closes.shift(-1 - horizon)`,持有 H+1 天。**Codex 發現的。**

```
                      41 天（錯）        40 天（正確）
打亂 − 隨機          +1.88%  t=2.32     −0.01%  t=−0.02
真模型 − 打亂        +0.70%  t=0.54     +3.14%  t=2.82
```

**「對照組太弱」和「73% 是因子傾斜」都不成立。** 而 LightGBM 反過來
變成顯著。

**最致命的是:我的測試把錯的慣例釘住了。** 程式與測試同時寫,兩邊照
同一個誤解,所以測試通過而行為是錯的。**測試驗證了我的理解,不是行為。**

### 5-2. 「超過隨機 95% 分位」不能重算，只能退休

那個門檻來自弱虛無。換成嚴格虛無後,加法與乘法兩種搬法給出**相反判定**
(+133.61% 成立 / +153.95% 不成立),而真測需在 OOS 跑 200 組 —— 禁令 6 禁止。

**由一個測不到的選擇決定的結論,不是結論。** 11 處引用全部加註撤回。

### 5-3. 累積報酬在 n≤36 不可 falsify

樣本外 +138.83% 的 95% 區間是 **[−13.34%, +587.23%]**,
**報告自帶的七個基準全部落在裡面**。

**包含我當成最可靠負面結論的「輸 0050 −103 pp」** —— 它和正面結論
一樣做不出來。兩個方向要用同一把尺。

### 5-4. 容量數字有缺價污染（Codex 發現同一類，我驗證自己也有）

`per_date_mean` 用 `skipna=True`,**缺 T+H 報酬的成交佔掉位子後從
逐日平均裡消失**。實測 3% 的成交:

```
位子     成交    缺報酬     佔比   首例
 10      360     11      3.06%   2311 @ 2018-04-13（日月光下市）
 20      694     22      3.17%   同上
```

偏誤方向向上(丟掉的是停牌／下市的名字),所以第三節那些數字**可能
被高估**,已標記 `invalid_pre_guard`。

### 5-5. 多重測試門檻算錯，挑出最沒訊息的一格

第一版拿「超額」比一個用**中位數 SE** 算的門檻。各格 SE 差 61 倍,
結果它挑出「連兩根漲停/H=40」(+3.399%)說值得追 —— 而那格
n=34 日、**t=0.54**,是整張網格最沒訊息的一格。

**t 已經除掉各自的 SE,所以只能比 t。**

### 5-6. 路徑相依的結論被自己的對照實驗收窄

我用兩個**不同**的擾動比出「數百 pp → 24 pp」。做了真正的對照實驗
(同一擾動餵兩個方案)之後:報酬全距只有 2/3 支持定期換倉,
**槽位排隊自己的全距本來就是「數十 pp」不是「數百 pp」。**

乾淨的訊號是**成交重疊**(3/3 一致),不是報酬全距。

### 5-7. 我和 Codex 同一天各自建了一個「單一來源」

```

我      validation/event_study.forward_returns(..., horizon)

```

**兩邊都在寫「重複實作很危險」的文件時做了這件事。** 而合併是乾淨的

## 六、方法上學到的六條（已寫進 CLAUDE.md）

```
1. 累積報酬不可當結論句          用每趟配對差異 + bootstrap 區間
2. 報告必須保存逐期序列          沒存的報告，不確定性永久不可知
3. 多重測試格子數跨工作單累計     目前 71 格，門檻 2.92
4. 「若 X 則回報」要寫判定句      原始數字不等於回答
5. 結論性回測用定期換倉          槽位排隊有路徑相依
6. 統計顯著 ≠ 賺錢               在此差 5.4 年
```

第 6 條的推導:

```
證明效應 ≠ 0（跨 1.709%）      需 173 事件日 ≈ 0.9 年
證明淨為正（跨 0.628%）        需 1,279 事件日 ≈ 6.3 年
```

樣本需求與距離的平方成反比,所以後者要 7.4 倍的時間。
