# 門檻方案與實際換手成本原理

## 為什麼門檻要分三種實驗

絕對 `edge_z`、逐日相對排名與定期全換倉回答不同問題，不能只留下事後
最好看的方案。E1 在同一決策日內排序，避免把市場整體時序水準混入選股；
E2 檢查統計顯著性門檻；E3 固定每 60 個交易日重選 Top 3，消除「槽位剛好
何時釋放」造成的路徑依賴。

三者的參數只可在截至 2023-12-29 的開發集比較。`--end` 才是資料載入的
物理邊界；`--dev-end` 只控制訓練切分，不能用來保護評估資料。

## E3 為什麼必須重算成本

定期換倉改變實際成交資金與次數，因此不能引用舊策略的換手率。模擬器以
每筆已平倉交易的實際配置金額計算：

```
週換手率 = 已成交配置總額 / (交易日數 / 5)
年化成本拖累 = Σ(配置額 × 該股分層來回成本率) / (交易日數 / 252)
```

成本率仍只取自 `taiwan_quant/config/costs.py`，大型股與中型股滑價分層不在
回測器重寫。這兩項是模擬結果的一級輸出，所有方案都並列顯示。

## 初步開發集結果

2015-01-01 至 2023-12-29 載入、60 日持有、150 檔標的池的 E1 Top 5%
仍未達門檻：動能 1630/65、籌碼 1596/64、均值回歸 1706/67，訊號／成交
比約 24–25:1。因此 Top 5% 不可被選為合格方案，仍須完成 E1 10/20、E2、
E3 與 140/150/160 擾動比較後才能定案。
