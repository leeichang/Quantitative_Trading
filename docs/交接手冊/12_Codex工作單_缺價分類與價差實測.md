## 第二部分：任務

### 任務 AF：暫停後復牌的結算政策（最高優先，它解鎖其餘）

`validation/delisting.MissingPriceKind` 目前把第 2 類歸進
`SUSPENDED_OR_MISSING` 然後拋錯。需要新增一類與一條結算規則。

**建議的規則，以及為什麼：**

```
T+H 缺價 → 往後找第一個有價交易日 → 用那天的收盤結算
```

理由是**那就是真實持有人的處境**：暫停交易期間你賣不掉，所以出場時點
就是復牌日。這不是估計值，是機制事實。

⚠️ **必須有上限。** 復牌隔太久就不是同一件事了：

```
□ 上限建議 20 個交易日（一個月）。超過仍然 fail closed
□ 上限必須是**顯式常數 + docstring 說明依據**，不是魔術數字
□ 實際延長天數要記進結果，不可靜默吸收——它是報酬期間的一部分
```

⚠️ **不可以用前值回填。** 那是 2026-09-17 的任務 M 特別警告過的方向：
「把真停牌的日子憑空補出價格，那比缺值更糟」。用**復牌日的真實收盤**，
不是暫停前的最後價格。

**驗收：**

```
□ 三類各有一個真實歷史案例的單元測試
  第 1 類 2311 @ 2018-04-13（下市）
  第 2 類 3702 @ 2018-08-01 → T+H 2018-09-27 → 復牌 2018-10-01
  第 3 類 2451 @ 2023-11-06（尾端截斷）
□ 第 2 類要有一個「復牌太久所以仍然拋錯」的測試
□ 實際延長的交易日數出現在結果物件上，不只在 log 裡
```

### 任務 AG：回補最後揭示買賣價（最高價值）

**這是本週最重要的未完項，因為它決定一個核心結論是真的還是假的。**

TWSE 每日行情本來就有這兩欄，而回補腳本把它們丟掉了：

```

  最後揭示買價 9.81   最後揭示賣價 9.82   → 半價差 0.051%
```

`stock_daily` 的欄位只有 `open/high/low/close/volume`。

**為什麼這件事決定一個結論：**

`config/costs.py` 的零股滑價 0.3%／0.4% 是禁令 4 的明文規格，
**沒有量測支撐**；整股 0.1% 有 490 筆實證。而滑價是 4 萬元零股單
1.071% 來回成本裡的 0.600%——**最大的一項，也是唯一沒量過的一項。**

主線新增的 `config/slippage.py` 用跳動單位估半價差，在 133,333 元、
三分之二標的買得起整張時落在 0.1051%，與舊模型的 0.1000% 幾乎一致
——**它重現了唯一有量測的那個數字**。但 40,000 元那一行舊值是
跳動單位的 3.1 倍，而且比 3 倍倍數還高。

```
零股滑價（單邊）        來回成本   年化       年化區間            含零?
0.30%（禁令 4）        1.071%   +4.09%   [−0.13%,  +8.53%]   含零
0.20%                 0.871%   +5.40%   [+1.14%,  +9.89%]   不含零
```

買賣價一補，這件事就從推論變成量測。

## 報數字的規矩（累積到第八張工作單）

### ⚠️ 新增：缺價的三類要分開報，不可合併成「缺價 N 筆」

下市、暫停後復牌、尾端截斷是三種不同的事，結算規則也不同。
合併計數會讓「政策對不對」變得無法檢查。

### ⚠️ 新增：滑價這類參數要標「規格」或「量測」

禁令 4 的 0.3% 是規格，整股 0.1% 是量測（490 筆）。
**兩者在報告裡必須可分辨**——本週的核心結論就卡在這個區別上。

### 「若 X 則回報」要寫出判定句

工作單 09 任務 W 問 E1/E2 是否仍相同，你給了表格沒給判定。
**原始數字不等於回答。**

### 多重測試的格子數跨工作單累計

目前約 71 格，門檻 2.92。報告要寫「本輪新增幾格、累計幾格、門檻多少」。

### 不要拿「超額」比一個用中位數 SE 算的門檻

各格 SE 差 61 倍時，那個算法會挑出 SE 最大的格子。**只能比 t。**

### 累積報酬不可當結論句

樣本外 +138.83% 的 95% 區間是 `[−13.34%, +587.23%]`，
**七個基準全落在裡面**。結論句用每趟配對差異。

### 報告必須保存逐期序列

沒存的報告，不確定性只能靠重跑取得——而那是禁令 6 擋住的。

### 改動的腳本必須實際執行並附輸出

`1,056 passed` 證明測試通過，不證明腳本能跑。

### 不要在未驗證旗標的 grep 後面串 `|| echo "無殘留"`

本機 `rg` 經 rtk hook 解析到 BSD `grep`，旗標錯誤會觸發 fallback，
印出假的「乾淨」報告。改用直接掃檔的 Python。
