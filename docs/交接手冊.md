## 0. 這個 repo 有什麼

```
Quantitative Trading/
├── qlib-tw-trader/     台股交易與預測系統（Qlib + FastAPI 後端 + React 前端）
├── taiwan-quant/       台股週頻 triple-barrier 量化研究系統（只出建議，不下單）
├── docs/               專案文件（本手冊在此）
└── .planning/          GSD 規劃文件
```

**為什麼 clone 下來體積很小（~6MB）？**
`.gitignore` 排除了所有**可重建 / 可重抓 / 本地生成**的檔案：

| 被排除 | 大小 | 如何重建（見下文對應章節） |
|--------|------|---------------------------|
| `taiwan-quant/data/history.db` | ~1GB | 跑 backfill 腳本從 FinMind/TWSE 重抓 → §3 |
| `qlib-tw-trader/data/data.db` | ~47MB | 跑 backfill 腳本重抓 → §4 |
| `.venv/`（兩個專案各一） | 大 | `pip install` 重建 → §2 |
| `frontend/node_modules/` | 大 | `npm install` 重建 → §4 |
| `data/models/`、`data/qlib/` | 大 | 重訓 / 重匯出 |
| `.env` | 小 | 手動填 API token → §1 |

**所以：程式碼、設定、文件全在 git 裡；資料與依賴照本手冊重建。**

## 1. 前置需求

### 系統
- **Python 3.12.12**（兩個專案都用這版；`taiwan-quant` 硬性要求 `>=3.12`）
- **Node.js 18+**（`qlib-tw-trader` 前端，Vite 6）
- （可選）**Docker + Docker Compose**（`qlib-tw-trader` 一鍵起服務）
- macOS / Linux（腳本用 `.venv/bin/python` 路徑，Windows 需改 `.venv\Scripts\python`）

### API Token（資料來源）
- **FinMind API Token** — 台股歷史資料主來源
  - 免費註冊：https://finmindtrade.com/
  - 免費層：600 requests/hour
- （可選）**Telegram Bot** — 週頻計畫推播用（不推播可略）

### Clone
```bash
git clone https://github.com/leeichang/Quantitative_Trading.git "Quantitative Trading"
cd "Quantitative Trading"
```

## 3. taiwan-quant — 資料重建與執行

### 3a. 設定 API Token
```bash
cd taiwan-quant
# 建立 .env（此檔被 gitignore，不會進 repo）
cat > .env <<'EOF'
FINMIND_API_TOKEN=你的_FinMind_token
# 選填：要推播才需要
TELEGRAM_BOT_TOKEN=你的_bot_token
TELEGRAM_CHAT_ID=你的_chat_id
EOF
```
> token 讀取：`os.environ.get("FINMIND_API_TOKEN")`。腳本會自動讀 `.env`。

### 3b. 重建 history.db（~1GB，從 2015 起）
分階段跑（照順序）：
```bash
# 1. 證券主檔（含已下市，解 survivorship）
.venv/bin/python scripts/backfill_finmind_history.py --phase master

# 2. 建歷史標的池（逐季快照，用成交金額排名）
.venv/bin/python scripts/snapshot_universe.py

# 3. 價格（OHLCV，11 年）
.venv/bin/python scripts/backfill_finmind_history.py --phase prices

# 4. 籌碼（三大法人、融資融券）
.venv/bin/python scripts/backfill_finmind_history.py --phase chips

# 5. 還原股價（由除權息回推）
.venv/bin/python scripts/backfill_adj_from_dividends.py

# 進度檢查（任何時候）
.venv/bin/python scripts/backfill_finmind_history.py --status
```
> **注意免費層 600 req/hour 上限**，全量回補會分多小時。可用 `--limit N` 先抓少量測試、`--delay` 調請求間隔。
> 資料庫預設路徑 `taiwan-quant/data/history.db`，可用 `--db` 改。

### 3c. 產週頻交易計畫
```bash
.venv/bin/python scripts/weekly_plan.py                    # dry-run，只印不發
.venv/bin/python scripts/weekly_plan.py --send             # 實際 Telegram 推播
.venv/bin/python scripts/weekly_plan.py --stocks 2330 2317 2454
```
管線：資料載入 → 特徵 → 柵欄推導 → triple-barrier 標記 → 訓練/預測 → Top 3 選股 → 部位規模 → Telegram 推播

### 3d. 驗證 / 診斷腳本
```bash
.venv/bin/python scripts/validate_oos.py            # 樣本外驗證
.venv/bin/python scripts/validate_oos_trailing.py
.venv/bin/python scripts/diagnose_barrier_params.py
.venv/bin/python scripts/diagnose_families.py
```

## 4. qlib-tw-trader — 資料重建與執行

### 4a. 設定 .env
```bash
cd qlib-tw-trader
cp .env.example .env
# 編輯 .env，填入 FINMIND_API_TOKEN
```

### 4b. 重建 data.db（~47MB）
```bash
# 回填單一股票完整歷史（OHLCV/還原股價/PER/三大法人/融資融券/外資持股）
.venv/bin/python scripts/backfill_stock.py 2330 2020-01-01 2026-01-28
# 多檔就多跑幾次，或看 scripts/ 內批次腳本
```

### 4c. 啟動（方式一：Docker，最簡單）
```bash
docker compose up --build
```
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- Swagger 文件: http://localhost:8000/docs

### 4d. 啟動（方式二：本地手動）
後端：
```bash
.venv/bin/uvicorn src.interfaces.app:app --reload --port 8000
```
前端（另開終端）：
```bash
cd frontend
npm install          # 重建 node_modules
npm run dev          # Vite dev server
```
初始化因子（第一次跑）：
```bash
curl -X POST http://localhost:8000/api/v1/factors/seed
```

### 4e. 訓練 / 回測
```bash
.venv/bin/python scripts/train_weeks.py
.venv/bin/python scripts/evaluate_models.py
.venv/bin/python scripts/calc_backtest_ic.py
.venv/bin/python scripts/simulate_timing.py
```

## 6. 常見問題

**Q: clone 下來沒有 `.venv` / `node_modules` / `.db`？**
正常。這些被 gitignore，照 §2/§3/§4 重建。

**Q: FinMind 回補很慢 / 被擋？**
免費層 600 req/hour。用 `--delay` 加大間隔、`--limit` 分批。TWSE 官方端點連抓數百次會被 WAF 擋（307），**不要繞過**，改用 FinMind API。

**Q: `.env` 沒進 git，token 怎麼帶到新機？**
安全考量，密鑰**絕不進 git**。到新機手動重填（FinMind 網站重拿即可）。

**Q: qlib-tw-trader 原本的 git 歷史？**
本 repo 為合併後的單一 repo。qlib-tw-trader 原始 commit 歷史保存在原 fork：`https://github.com/Docat0209/qlib-tw-trader.git`
