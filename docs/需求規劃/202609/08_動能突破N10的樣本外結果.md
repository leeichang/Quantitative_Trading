```

毛/趟 +7.60%｜淨/趟 +6.93%

**超出隨機 10 檔的 95% 分位**（+129.57%）。隨機的分布很寬

## 不成立的部分：贏不過 0050

2024-2026 是 AI 集中行情，0050 的權重高度集中在台積電，等於單押最強的
那一檔。策略選 10 檔分散，結構上吃不到那一段。

這不是策略的缺陷，是**標的池的設定問題**：策略只能從市值前 150 名的
個股裡選，**ETF 從來不在候選名單裡**。

```
標的池      market_cap 時點池前 150 名（個股）
0050        不在池內，所以策略永遠不可能選它
```

如果這個區間的最佳決策是「買 0050 不動」，策略在設計上就沒有機會做出
那個決策。

## 成本假設的實證依據

```
來回 0.671% = 手續費 0.1710%（6 折）+ 證交稅 0.3000% + 滑價 0.2000%
```

滑價 0.1%/單邊的依據（490 筆實際持倉）：

```
台股跳動單位隱含的半價差   中位 0.0937%｜平均 0.1116%｜最大 0.2482%
  0~50 元    0.0973%
  50~100 元  0.0708%
  100~500 元 0.1411%

市場衝擊  4 萬元部位對當日成交額中位僅 98.9 ppm，超過 1% 的只有 4/490 筆
```

台股開盤是**集合競價**，所以半價差是滑價的**上限**而非下限——4 萬元的單
幾乎不會推動開盤價。取 0.1% 是保守的。

敏感度：

```

## 這一組參數怎麼來的

現行系統把分數經過三層，實測那三層在毀訊號：

```
經過校準器→門檻→槽位   60 日 CPCV 中位數 +5.06%｜5% 分位 −27.86%
直接用原始分數排序      40 日 CPCV 中位數 +94.39%｜5% 分位 +13.68%
```

| 層 | 做了什麼 | 後果 |
|---|---|---|
| 校準器 | 分數 → 12 個等級的箱平均 | 解析度從連續變 12 級，大量平手 |
| 門檻 | 淨期望 > 0 且 > edge_z 個標準誤 | `edge_z` 1.0→2.5 對成交比毫無影響 |
| 槽位佇列 | 訊號排隊等槽位 | 99.8% 被擋，成交由排隊順序決定 |

所有先前的診斷都指向這三層：箱內 IC 0/18、tie-break 偏差 17.5 pp、
訊號/成交比 435:1、PBO 0.629~0.971。
