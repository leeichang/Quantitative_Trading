## 二、0050 對照組

### 為什麼它比等權更嚴格

等權持有 150 檔要每季調倉、付 150 次交易成本；0050 買一次就好。
**它是可以真的買到的東西。** 策略連它都贏不了，就沒有存在的理由。

### 結果（OOS 2019-01-29 ~ 2026-09-11，7.34 年）

```
等權買進持有（個股）   +701.37%   MaxDD 33.68%   年化 32.9%
0050 台灣50           +618.34%   MaxDD 33.83%   年化 30.8%
0051 中型100          +528.94%   MaxDD 31.30%   年化 28.5%
0056 高股息           +306.31%   MaxDD 26.89%   年化 21.1%
```

四個對照的排序符合直覺：等權 > 大型股 > 中型股 > 高股息，
回撤則是高股息最小。**這本身就是資料品質的旁證。**

## 三、下市股票的還原價

### 問題

`backfill_adj_close.py` 走 yfinance 的 Adj Close，但它查不到已下市的
股票——107 檔沒有還原價。而下市股票正是 survivorship 的關鍵樣本。

### 解法

FinMind 的 `TaiwanStockDividendResult` 免費層可用，且**對下市股票也有
紀錄**（實測 2311 日月光 4 筆、2325 矽品 3 筆）。它直接給：

```
before_price   除權息前收盤價
after_price    除權息參考價
factor = after_price / before_price
```

### 驗證：與 yfinance 比對 6 檔

```
代號    除息次數   中位相對誤差      最大      >1% 的列
2330      34      0.000000     0.008152        0
1301      13      0.000000     0.006313        0
2412      13      0.000082     0.008249        0
2454      16      0.000016     0.023307        3
2317      13      0.000000     0.203089      920
2881      18      0.000000     0.022222      963
```

2317 與 2881 的大差異**不是本方法的錯**：

```
2317  除權息法   12 個因子變動日，全部是真實除息日
      yfinance   42 個變動日，含 2016-08-22 ~ 09-13 的連續段
```

那段連續變動不是公司行為，是 yfinance 自己的資料抖動。
**除權息法只在官方除息日變動，方法學上更乾淨。**

但**只補缺口、不覆寫**既有的 yfinance 還原價——覆寫會讓先前所有的
驗證結論不可比。代價是資料庫裡混了兩種方法，此處揭露。

### 結果

```
還原價覆蓋率      95.8% → 99.40%
標的池成員覆蓋率   97.01% → 99.39%
有還原價的標的     1,111 → 1,218 檔（全部）
```

## 四、抓到一個影響所有先前結果的 bug

### 症狀

0050 的最大回撤算出 **84.20%**。2019-2026 之間台股沒有這種跌幅
（2022 年台積電也只跌約 50%），數字不合理。

### 根因

0050 在 **2025-06-18 做了 1:4 分割**（188.65 → 47.57）。還原價正確
處理了它，但有 11 天缺還原價。而 `loader._apply_adjustment()` 的做法是
「缺還原價時保留原始價」：

```
2021-04-06   原始 137.65（被保留，屬於分割前尺度）
鄰近日        還原後約 33.5
→ 單日 4 倍尖峰 → 假回撤 84.20%
```

**還原因子在兩次公司行為之間是常數**，所以正確做法是沿用前一個已知
因子，不是保留原價。

### 修正後

```
          修正前     修正後
0050      84.20%    33.83%
0051      40.39%    31.30%
0056      54.13%    26.89%
等權       47.05%    33.68%
```

### 這個 bug 的性質

它不會拋任何錯，只會讓**任何有缺還原價日的標的**在還原序列裡出現
尖峰。沒有分割的股票因子接近 1，尖峰只有 20% 上下，看起來像正常波動；
只有 0050 這種做過 4:1 分割的才暴露出來。

**先前五輪驗證的回撤數字都受它影響。** 本輪已重跑。

## 五、標的池代理：72.7% → 94.7%

### 問題

第一版用**日均成交金額**排名。拿今天真實的 0050+0051 名單驗證：

```
命中 109 / 150 = 72.7%
漏掉：1102 亞泥、1402 遠東新、1503 士電、2002 中鋼、2105 正新、2207 和泰車
```

全是**大市值但低週轉的傳產**。成交金額排名系統性偏向熱門股，
而 0050 / 0051 是市值加權指數，正好相反。

### 解法

TWSE `MI_QFIIS` 的「發行股數」欄位支援任意歷史日期。每季一次、
47 個請求就覆蓋 11 年：

```
市值 = 當日收盤價 × 發行股數
```

### 結果

```
排名依據      檔數   命中   命中率   漏掉的
市值          150    142   94.7%   2371、2455、2646、3005、4583、4919
成交金額      150    109   72.7%   1102、1229、1402、1476、1503、1504
```

市值版的組成也通過直覺檢驗：

```
2015  台積電、鴻海、中華電、聯發科、台塑化、國泰金   ← 當年真正的權值股
2018  台積電、鴻海、中華電、台塑化、台塑、南亞
2022  台積電、鴻海、聯發科、中華電、富邦金、台塑化
2026  台積電、聯發科、台達電、鴻海、日月光投控、國巨
```

對比成交金額版的 2018 是「國巨、華新科、玉晶光」——那是當年的**熱門股**，
不是權值股。

歷來成員也從 586 檔降到 **280 檔**，市值排名穩定得多。

### 仍然是代理

真實指數還有流動性門檻、產業分散、自由流通量調整，而且成分股審核
每季由指數公司人工核定。**真實的歷史成分股在免費來源取不到**——
元大只公布現況，指數公司的歷史審核公告沒有 API。這條限制留著。

## 八之二、補記：結果本身不穩定（2026-09-13 追加）

寫完本文後發現市值快照只建了 47 期中的 24 期——缺的 23 期都是元旦或
週末，MI_QFIIS 回 `stat=OK` 但 `data=[]`，被誤判成抓取失敗。

修法是往前找最近一個交易日（與價格的處理一致），補齊到 46 期
（2015-01-01 那期缺，因為價格從 01-05 才開始，往前沒有資料——那是正確的）。

**純資料完整性修正，策略參數完全沒動。** 但結果：

```
組合             補齊前（24 期）   補齊後（46 期）    差異
動能突破 × 60     +1544.05%       +1738.27%       +194 pp
籌碼跟隨 × 60     +1076.79%       +1022.05%        −55 pp
均值回歸 × 60      +954.87%        +123.93%       −831 pp  ←
均值回歸 × 120     +294.62%        +802.42%       +508 pp  ←
等權對照           +701.37%        +688.79%        −13 pp
```

對照組只動 13 個百分點（合理），**策略擺盪數百個百分點**。

### 這不是 bug，是路徑相依

60 日持有下 99.8% 的訊號被槽位擋掉。標的池換掉幾檔，排隊順序就變，
整條權益曲線跟著變。

**所以第七節的「不建議推播」不只成立，理由還更強了**——
連「哪一組最好」都不穩定。第 6 節那張表應該被讀成「一次抽樣的結果」，
不是策略能力的估計。

## 九、限制（誠實聲明）

1. **有效獨立樣本 15 ~ 71 個。** 60 日持有一年只有 4.2 個不重疊樣本。
2. **DSR 全部未達顯著。** 最好的 0.1197。
3. **OOS 期間仍以多頭為主**（等權 +701%），雖含 2020 與 2022 的修正。
4. **標的池是市值代理**，命中真實成分股 94.7%，非真名單。
5. **還原價混用兩種方法**：yfinance Adj Close（1,111 檔）+ 除權息推算（107 檔）。
6. **99.8% 的訊號被槽位擋掉**，成交高度路徑相依。
7. **本輪是第七次看 OOS。** 雖然只修 bug 沒調參，過擬合風險仍然增加。
8. **策略結果在重跑之間擺盪數百個百分點**（見第八之二節）。
   這是目前最嚴重的問題——連「哪一組最好」都不穩定。
