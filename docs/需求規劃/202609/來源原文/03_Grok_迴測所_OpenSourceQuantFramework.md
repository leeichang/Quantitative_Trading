### 架構（開源 + Claude Code / Codex）

- **資料**：用 Yahoo Finance，失敗改走 **FinMind**（雙資料源 fallback）
- **研究端**：**vectorbt / backtesting.py**，由 Claude Code 或 Codex 寫策略

- **架構頁**有可直接貼給 agent 的任務稿
- **策略頁**說明四套規則：**均線交叉、RSI、MACD、唐奇安（Donchian）通道**

## 本來源的獨有觀點整理

1. **同一套策略規則實作兩次**（Python 研究端 vectorbt/backtesting.py + TypeScript 回測核），可作為交叉驗證手段
2. **資料源 fallback 機制**：Yahoo Finance 失敗自動改走 FinMind
3. **四套策略比較**（均線交叉 / RSI / MACD / 唐奇安通道），用 Sharpe + CAGR + 回撤三指標排名，非單一指標
4. **Telegram Token 只留在使用者裝置端**，不上傳伺服器
5. 回測窗口提供**兩年／一年切換**比較，避免單一窗口結論
6. 產出帶「研究註記」欄位，讓人工補上理由（人機分工）
