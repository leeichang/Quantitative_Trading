## 開發規範

- **TDD**：先寫測試（RED）→ 最小實作（GREEN）→ 重構。
  測試的預期值要**手算**，不可拿程式輸出反填
- **不動紅線**：`PULLBACK_QUANTILE`、`edge_z`、槽位數、持有期網格屬策略
  參數，要調必須先確認評估區間沒被看過（見交接手冊）
- **每項改動附一份** `../qlib-tw-trader/docs/原理說明/YYYY-MM-DD_*.md`，
  寫清楚「為什麼這樣做」而不只是「做了什麼」
- 其餘風格與禁令見 `CLAUDE.md`

## 驗收清單

寫完程式、交件之前，對自己的改動逐條檢查；審別人的程式時用同一份：

### look-ahead bias（最高優先）

1. **T 日決策是否只用了 T 日收盤前可得的資料？**
   特別檢查：`shift()` 方向、`rolling` 視窗對齊、`merge_asof` 的 `direction` 參數
2. **triple-barrier 標記是否只在標記時使用未來資料，特徵計算完全不用？**
3. **進場時點是否為 T+1 開盤？** 用 T 日收盤價進場屬 look-ahead
   （三大法人資料 T 日約 15:00–18:00 才公布）
4. **財報／月營收是否用 `announce_date` 對齊**，而非期間結束日？
5. **look-ahead 掃描器是否用物理截斷**，而不是 qlib 的 `end_time`？
   `end_time` 只裁切輸出範圍，運算式仍會讀底層未來資料 —— 用它做的截斷測試是無效的

### survivorship bias

6. **標的池是否用「今日」的成分股名單回溯歷史？**
   目前已知：`universe` 用市值排名代理 0050+0051，這是已記錄的近似，
   但任何**新增**的回溯邏輯都不得加深這個問題
7. 退市／被剔除的股票是否留在歷史樣本內？

### 交易成本

8. **是否呼叫 `taiwan_quant/config/costs.py`？** 有沒有任何地方自己重寫費率？
9. **滑價是否分層**（0050 = 0.3%、0051 = 0.4%）？
10. **最低手續費**：小額部位是否用 `max(金額 × 費率, 20)` 而非純比例？
    （40 萬資金做零股，部位常低於 23,392 元門檻）
11. **證交稅**是否只在賣出收 0.3%？有沒有誤收在買進？
12. **成本敏感度**是否至少三檔並列（無成本 / 含手續費稅 / 含滑價）？

### 回測方法論

13. **換手率是否為一級輸出？** 報告有沒有並列週換手率與年化成本拖累？
    實測教訓：週換手 9.9% → 年化成本 5.51%；271.5% → 115.56%
14. **valid/live IC 相關係數是否有監控與回報？**
    接近 0 或為負代表模型選擇機制失效
15. **Walk-Forward**：訓練窗口是否嚴格在預測期之前？embargo 是否 ≥ label 跨度？
16. **Out-of-Sample**：OOS 區間是否被用來調過參數？（查 git log 與參數提交時序）
17. **多重測試**：掃了 N 組參數後，是否回報 Deflated Sharpe 或 PBO？
18. **對照組**：報告是否並列等權買進持有、0050、隨機進場？
19. **報告是否誠實**？策略跑輸對照組時，有沒有如實寫出來而不是調參數掩蓋？

### 工程品質

20. **版本紀錄**：`strategy_version` / `model_version` / 參數是否有落盤？
21. **不可變性**：有沒有函式就地改寫傳入的 array / DataFrame？
    （pandas 3.0 copy-on-write 會讓這種寫法直接壞掉）
22. **裸 `except:`**：有沒有吞掉所有例外（含 `KeyboardInterrupt`）？
23. **秘密**：Token / Chat ID 是否走環境變數，程式碼中無明文？
24. **unit test**：每個特徵與標記函式是否有比對**手算值**的測試？
    預期值是手算的還是拿程式輸出反填的？後者等於沒測
25. **型別註記**：函式簽名是否完整標註？
26. **檔案長度**：是否超過 800 行？

### 投組與部位

27. **投組約束**是否實作且有測試（同產業 ≤ 2、高波動 ≤ 1、相關係數 < 0.7）？
28. **部位規模**是否取兩道上限的小值（1% 風險倒推 vs 33% 資金上限）？
29. 算出 **< 1 股**時是否不推播？
30. **零股**：輸出單位是股數而非張數？（40 萬買不起一張台積電）
